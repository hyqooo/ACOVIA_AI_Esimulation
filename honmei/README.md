## 30秒でわかる本命シナリオ

**一行説明（5.5年間、一字も変えない）**
> 不妊治療中に、ひとりでは決めきれないことがある日に、経験者と45分だけ話せる場所です。

**中核の設計**：45分のセッション。**前半15分は整理しない時間**（相槌・繰り返し・沈黙のみ。質問は「それで？」「他には？」の2つだけ）。後半30分で4つの箱に分ける（今日決めること／まだ決めないこと／足りない情報／次の一歩）＋再検討条件。
→ 「傾聴」は商品名にも価格表にも一度も登場しない。**工程として設計に埋め込んである**（学び1）。
