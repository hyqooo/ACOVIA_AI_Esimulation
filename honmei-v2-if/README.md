## 30秒でわかる結論

1. **ピボットの方向は「どの限界が来たか」で決まる。** 需要ゼロ（V4）なら形を変えても救えない（撤退が正しい）。頻度が伸びない（V2）・利益が出ない（V7）なら**単価の階層**を足す方向、供給が壊れる（V3）なら**恩送り・非同期**の方向へ曲がる
2. 採点の第1候補は**P-A「二階建て」**：傾聴15分（本体・変えない）の上に、決めどきが来た人だけの上位商品「整理の45分」を載せる。**Ver1の45分設計を、順序を逆にして再利用する**（Ver1＝整理が本体で傾聴は工程／ピボット版＝傾聴が本体で整理は選択肢）
3. 実現パスでは、営業黒字が1年前倒し（2030年＋30万円）、2031年に売上509万円・利益115万円。**ただし専業化には依然届かない。** ピボットが買ったのは生計ではなく、「生計問題を解ける可能性のある構造（単価の階層）」である
4. **ピボット自体にも停止条件を先に置いた**（R2-8：15分の「アドバイスされた」指標が2四半期連続10%超なら上位商品の案内を止める）。傾聴の場が営業の入口に変質したら、そのピボットは失敗である
