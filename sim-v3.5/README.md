## 30秒の結論

**新しい戦略は1つも足していない。変えたのは順序と速度だけ。それで2億7,000万円の差が出た。**

| | 一周目 | **二周目** |
|---|---|---|
| 初売上 | 2027年7月 | **2026年11月**（8ヶ月早い） |
| G-CHALLENGE | KIBOW賞のみ | **大賞＋KIBOW賞のダブル受賞** |
| 2031年売上 | 8億2,000万円 | **10億9,000万円** |
| 報酬2,000万円 | 2031年 | **2030年** |
| 詰まった場所 | 需要（利用率3%の壁） | **供給（サポーターが3ヶ月遅れる）** |
| 6条件 | 完全達成3／部分3 | **完全達成5／部分1** |

**6条件のうち、一周目で届かなかった条件4（受賞・10億）と条件5（報酬2,000万）が、二周目で達成に変わった。** 残る部分達成は条件3（男性ペイン）のみ——15.4%まで改善したが、全国水準約16%にわずかに届かない。

## 金額に出ないが、決定的だった3つ

差分の大半は L1〜L3（研修・営業・大企業）の前倒しだが、**帳簿に出ない3つの行動**が、その前倒しを可能にした。

| いつ | 何を | 効果 |
|---|---|---|
| **2026年10月** | エントリー資料の図版・裏取りを**8万円でスポット外注** | 倉元さんに動かせない締切が2つ乗る構造を解き、**人事部ヒアリングが3社→12社** |
| **2026年9月** | 山口さんに「**いつ頃から時間が出せそうですか。それまでは同席だけにしておきませんか**」と聞いた**15分** | 曖昧な「担当」の看板が消え、プロダクトの持ち手が確定 |
| **2027年3月** | 法人設立と同時にベスティングを合意した**1時間** | 誰も悪くない時点で決められた。シリーズAで投資家が確認したときは解決済み |

**8万円と15分と1時間。** これがこの二周目で最も安く、最も効いた投資である。

## 人員最適値の答え

**「何人必要か」では決まらない。「締切が動かない仕事を、1人1つに保つのに何人要るか」で決まる。**

一周目で最初に壊れたのは総稼働ではなかった。2026年10月、倉元さんに「エントリー資料の締切（11/2）」と「企業の年度稟議」という動かせない締切が2つ同時に乗った。総量は足りていた。**衝突が原因だった。**

詳細は `growth-v3/15-staffing-optimum.md`。要点：

- **2027年に週22〜27時間 → 38〜43時間へ**（月10〜30万円の投資で1.6倍）。この5年でこんな効率の区間はここだけ
- **正社員を採る前に、業務委託で職能を試す**（二周目では営業1人目が3ヶ月・30万円で合わないと分かった。正社員なら1年と600万円かかっていた）
- 営業を**「入口（菅原さん）」と「詰め（倉元さん）」**に割る

## 二周目で新しく分かったこと

学びを実装した結果、**詰まる場所が1段上がった**。需要で詰まっていたのが、供給で詰まるようになった。

- **L14｜対外シフトと品質維持の両立には、型だけでなく「見る人」が要る。** サポーター統括の採用は、代表の対外シフトと**同時**でなければならない
- **L15｜需要の伸びに対し、供給は常に3ヶ月遅れる。** サポーターは研修→ロールプレイ→評価→SVで1人3ヶ月。**3ヶ月先の必要数から逆算して募集する**仕組みが要る

三周目があるならこの2つを初期装備にする。推定効果は2031年に11.5億円前後。ただし、また新しい詰まり方が出る。

## 正直な但し書き

**10億9,000万円は「2031年ギリギリ」であって、余裕はありません。** 供給制約による後ろ倒し（6,000万円）が2四半期長引いていたら10億を割っていました。学びを全部実装してもなお綱渡りです。

また、**男性利用率は2周やっても全国水準に届きませんでした。** 打ち手はすべて効いた上で届いていないので、これは打ち手の不足ではなく構造の深さを示しています。ToCのM4は5年ではなく10年の指標として置き直すべきかもしれません。
