## 1.【CEO】基本方針——3つの原則

**成功の定義**（憲法どおり）：年商やVC型成長ではなく、①MVVを体現できている、②長期的に価値を発揮し続けられる、③その上でうまくいけばグロースできる。今回の社長与件は、これに**「3年で2名の生計が成立する」という具体的な床**を追加したものと解釈する。

### 原則1｜C2Cは価値の源泉、B2B2Cは生計の源泉

単価感度分析（`honmei-v3/09-price-sensitivity.md`）の結論は動かない：傾聴セッションは中核帯（30分3,000〜5,000円）に留めるべきで、**セッション単価だけで2名分の年収2,000万円は構造的に賄えない**。したがって、トークタイムは「価値の証明と成果データの生産装置」、生計は**B2B2C（クリニック・企業・自治体）と副代表が動かす別トラック**で立てる。これはVer4の主題（二本柱）を、社長与件の数字で確定させたものである。

### 原則2｜証拠の階段を飛ばさない

3年の逆算は急だが、順序は変えない：**E3（非知人・有償・反復）の証拠 → 成果データのパッケージ → B2B2Cパイロット → 契約の再現**。証拠がないままB2B営業に走ると「いいサービスですね」（失敗パターン1）で終わる。逆に、証拠づくりに3年かけたら目標に届かない。**Phase 0の締切は2026年10月31日（現実の90日Gate計画と同じ）**とし、以後は各Phaseに撤退・転換条件を先置きする（D-004の学び）。

### 原則3｜Missionの主語は変えない。ただし商材は複線化する

「選ぶ本人」が主語であることと、K'の4つの栓（件数KPI化・謝礼圧縮・紹介料/掲載料・相談者に触れるAI、は締めたまま）は3年間不変。一方で、**MVP検証後は自由**という与件を使い、意思決定伴走型（Decision Note）は捨てずに**B2B向け商材（従業員支援・患者支援プログラムの中身）として後段で再登板させる**。傾聴と意思決定支援は競合仮説ではなく、C2C入口とB2B商材という役割分担で共存させる。

## 3.【CEO】【CPO】フェーズ計画

### Phase 0｜証拠づくり（現在〜2026/10/31）——現実の90日Gate計画をそのまま完走する

- やること：8/25定例で決まる相談会（トークタイム）を実施し、Gate①〜⑤（利用瞬間・顧客成果・人間介入・再現性経済性・流通支払者）を判定する。**このPhaseに売上目標は課さない**
- 経営側の追加タスク（検証と並行、売り込みはしない）：Gate⑤のために「支払者候補（クリニック・企業）に話を聞くだけのヒアリング」を2〜3件仕込む
- **撤退・転換条件（R-H1）**：10/31時点でGate②（明確化と行動）が1件も観測できなければ、傾聴型の設計を見直し（対象トリガー・時間尺の変更）、Phase 1の開始を最大2ヶ月延期する。**延期は1回まで**

### Phase 1｜有償化と支払者探索（2026/11〜2027/6）

- C2C：有償トークタイム開始（中核帯30分3,000〜5,000円。感度分析の下限「分70円」を割る価格は設定しない）。E3（非知人・有償・反復）の証拠を10件以上作る
- 成果データ：事後アンケート（8/17設計のもの）を成果指標（言語化できた・気持ちの変化・再利用意向）としてパッケージ化する【ソーシャルインパクト】
- B2B2C：クリニック1〜3院で無償〜低額パイロット。企業は1社話を聞く
- 別トラック：副代表が週7〜8時間で検証開始。まずCAC低減（発信→トークタイム流入）、その後それ自体の収益化
- 法人化：**有償化と同時に合同会社を設立**（B2B契約に法人格が必要。設立コスト最小。株式会社転換は契約拡大期のオプション）【法務】
- **資金調達（必須。社長回答3・4：自己資本はほぼなく、何かしらの調達が必須）**：法人化と同時に日本政策金融公庫の創業融資300〜500万円を申請し、小規模事業者持続化補助金・自治体の創業助成を併用する。使途は運転資金（ツール・研修・広告・専業化前倒しの原資）。エクイティ（VC）は、Gate通過後の成長データがVC型を示した場合にのみ検討する（憲法どおり資本政策の切り替え条件を維持）【CFO】
- **撤退・転換条件（R-H2）**：2027/6末までに「非知人・有償・2回以上利用」が5名未満、かつパイロット継続希望が0件なら、C2C主軸を畳み、B2B商材（両立支援・研修）への全面転換を検討する

### Phase 2｜再現性と契約拡大（2027/7〜2028/8）

- 契約8〜12件へ。サポーター認定の型（研修・評価・報酬）を完成させ、「代表以外のサポーターでも成果が出る」ことを証明する（失敗パターン6対策）
- AI支援（チェックイン・要約・次の一歩）を運用に入れ、粗利率を55%→60%台へ改善（相談者に直接触れるAIはK'の栓のまま封印）
- **山口さんの稼働が最も細る期間**。属人作業を残さないため、Phase 1のうちに予約・決済・記録のツール化を山口さん主導で完了させておく【COO】
- 専業化判断点（社長回答5で確定）：**直近3ヶ月平均の月商が「本人報酬50万円＋変動費＋固定費按分」を賄い、翌6ヶ月の受注見込みが立った時点で、報酬ライン未達でも専業化を実行してよい**。順序は副代表が先行、代表は後追い可（社長回答1）
- **撤退・転換条件（R-H3）**：2028/8末までに契約が5件未満、または更新率が50%を割る場合、Y3の1,000万目標を1年後ろ倒しするか、事業構造の再設計（憲法の選択肢3=譲渡を含む）を経営会議にかける

### Phase 3｜生計の成立（2028/9〜2029/8）

- 契約15〜25件＋企業2〜4社。年商4,500〜6,000万円
- 副代表：ACOVIA報酬800万円超を確定させ、1,000万円を目標に継続。代表：600〜1,000万円（1,000万円は後追い到達可。社長回答1）

## 4.【CMO】需要と支払者の方針

- C2Cの言葉は顧客の言葉のまま：「不妊治療 つらい」「結果が悪かった日」「ただ聞いてほしい」。急性感情トリガー（悪い結果の当日〜翌日）をビーチヘッドとする現行仮説を維持
- 最大の競合は「何もしないこと」。無料代替（SNS・オープンチャット・無料AI）との差は「経験者が、あなたのためだけに、否定せず聞く」に絞って伝える
- B2Bの言葉は支払者の言葉に翻訳する：クリニックには「離脱・転院の背景にある心理負担への補完」、企業には「両立支援・離職防止」（次世代育成支援・くるみん等の制度文脈は営業材料として調査継続【秘書→週次情報収集】）
- 紹介経路：知人経由から、パイロット院・説明会協力者（岩田さん・丹野さん）経由の非知人流入へ段階移行。Gate⑤の判定材料とする

## 5.【COO】【CHRO】供給と組織の方針

- 役割分担：代表＝聞き手・品質・サポーター育成／副代表＝事業開発・財務・B2B営業・別トラック／山口さん＝予約・決済・記録・ツールの標準化（**2年間は2/3〜1/2稼働のため、「山口さんにしかできない状態」を作らないことが最優先**）
- サポーター供給：丹野さん回で出た「メンバー→サポーター循環」を供給モデルの本命とする。ただし需要証明前に集めすぎない（失敗パターン4）。Phase 1末までに認定サポーター3名、Phase 2末までに8〜10名
- 報酬：善意依存にしない。謝礼は分67円の現行水準を下限とし、認定・継続に応じた段階報酬を設計。スーパービジョン（月1回）と安全即応の当番制をPhase 1から運用
- 安全即応：セッション中の危機対応の一次責任者を**代表以外**に置く設計を検証する（代表に評価・安全・研修が集中すると壊れる——Ver1の学びの直接適用）。緊急連絡先リストの記入完了はPhase 0の必須タスク（現実の最優先ギャップ）

## 6.【法務・倫理】守る線

- 医療助言の境界・録音と匿名化・守秘義務は決定済みルールを維持。B2B展開時は「クリニックへの個人情報還流はしない」を契約の初期条件に置く（信頼の生命線）
- 会社形態：Phase 1で合同会社設立を推奨。インパクト重視の見え方が必要になった場合の一般社団法人化・株式会社転換は、支払者構成が固まってから再検討（憲法どおり形態変更は自由）
- K'の4つの栓は3年間緩めない。価格改定時には「アドバイスしない約束が守れているか」の点検（R2-8）を必ずセットにする

## 7.【VC】反対意見——この計画の弱点を先に言っておく

1. 初版最大の懸念だった専業化の順序問題は、社長回答5（月50万円見込みで専業化可）で解消した。代わりに**「調達必須（自己資本ほぼなし）」が新たな急所**になった。創業融資が下りない・遅れる場合、専業化の前倒しも供給拡大も止まる。融資審査に耐える事業計画書と初期実績（E3）づくりを最優先に置くこと。Y2→Y3の成長率（約2〜2.5倍）は依然高い
2. クリニック月10〜15万円の根拠はまだE0（仮定）。**支払う瞬間の証拠がゼロ**のままY1を終えたら、Y2以降の表は全部書き直しになる
3. 別トラックは「予防・啓蒙はやらない」（決定I-25〜I-27）との線引きが未決着。曖昧なまま走ると事業の主語がずれる（シナリオKの敗因）
4. 3年間で市場環境（保険適用範囲・無料AIの傾聴品質）が変わる。**無料AIとの差別化が「人だから」だけになった時点で価格は崩れる**——成果データの蓄積だけが防壁
5. それでも本計画を支持する理由：撤退条件が全Phaseに先置きされており、「決めないまま停滞する道」（シナリオD）を構造的に塞いでいるため
