## 30秒でわかる結論

1. **現実の出発点は、Ver1ともVer2とも違う。** Ver1は「45分9,800円を9月に有償開始する会社」、Ver2は「Phase7-8で開始判定保留中の会社」を起点にしたが、現実は**代表がサポーター役（聞き手）を自ら務め、以前のアンケート回答者に個別依頼して返信が来ている段階**——供給は実質1名（＋承諾2名）、需要はまだ無償協力の返信のみ。有償/無償・件数・録音などの運用条件は**未確認**（推測で埋めていない）
2. この出発点から動かせる**最初のレバーは1つだけ**（学びO：一度に1変数）。どれを最初に引くかで、4つの構造的に異なる賭け方になる：
   - **シナリオα｜需要が先**——代表が聞き手のまま、非知人・有償E3への最短距離を走る
   - **シナリオβ｜供給が先**——Experiment 01の設計どおり、認定3名と安全分離を作ってから募集する
   - **シナリオγ｜単価が先**——15分の上に「整理の45分」を早期に建て、生計構造への距離を縮める
   - **シナリオδ｜頻度が先**——返信をくれた数名と深く反復し、再利用のE3を最初に取りに行く
3. **4案とも、Ver2の撤退条件R2-1〜R2-6と4つの栓（K'）は共通の床として維持する。** 違うのは「何を最初に証明しに行くか」と「その間、何を意図的に証明しないままにするか」
4. 秘書の照合で、**新事実が1件**：専業化は3名一括ではなく、**代表2が先行する可能性が高い**（条件は同じ800万円/1,000万円。他2名のタイミングは未確認）。Ver1・Ver2はどちらも一括専業化を暗黙の前提にしていた——全シナリオの生計構造をこれで引き直した
