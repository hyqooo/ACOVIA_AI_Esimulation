# シナリオα｜需要が先——非知人・有償E3への最短距離

> **中心のレバー：需要（V4→V10）。** 供給・単価・頻度への投資を意図的に凍結し、「経験者に、ただ聞いてもらうことに、知らない人がお金を払う」という1点の証明に最短距離で向かう。
> 5年後の見立て（数字はすべて仮定）：セッション約2,400件/年・売上約400万円・サポーター約20名。**判定（事前の見立て）：需要が実在すれば4案で最も速く確信に到達する。実在しなければ4案で最も早く・最も安く撤退できる**

---

## 1. 起点になった観測（現実・証拠強度つき）

| 観測 | 強度 |
|---|---|
| アンケート回答者への個別依頼に返信が来ている——**個別に頼まれれば動く人は、実在する** | E3（ただし無償・協力ベース） |
| 需要側の有償E3はゼロのまま（学びT） | 事実 |
| オープンチャットの実投稿は「教えたがりで埋まり、流れて消えた」——競合は「無料で使えていて、たまに機能する場所」（学びS） | E3 |
| 代表が聞き手を務める体制が、追加投資ゼロで既に立ち上がっている | E3 |

**賭けの一文**：この事業の最大の不確実性はV4（需要）であり、V4が偽なら他のすべての投資が無駄になる。**だから他の全部を止めて、V4だけを最初に殴りに行く。**

## 2. 設計（最初の12ヶ月）

| 項目 | 内容 |
|---|---|
| 商品 | 音声15分・1本のみ（基本線6点は不変） |
| 価格 | 無償リハーサル（運用条件確認後）→**できるだけ早くお試し1,000円へ**。有償化の案内日を開始時に宣言する（V10の失敗側への栓） |
| 聞き手 | **代表のまま**（12ヶ月は交代を目標にしない）。ただし代表の実施上限（週n件）と安全即応者（セッション中は別の代表が待機）を先に宣言 |
| 集客 | 個別依頼→参加者の紹介→**個別依頼の外の経路を1つだけ**追加（当事者コミュニティでの一次発信等）。広告・LP大規模制作はしない |
| 動かさない変数 | V1（価格改定）・時間尺・V6（法人）・供給拡大（V3）。観測のみ：V2（再利用）・V5（即時性） |

## 3. 成功・失敗条件（先に書く）

- **成功**：2026年内に**非知人・有償・実施済のE3が1件以上**、2027年6月までに**個別依頼の外の経路から累計10件**。申込理由が「ただ聞いてほしかった」側で語られる（傾聴仮説の確認）
- **失敗**：有償化案内後、無償参加者・紹介からの有償転換がゼロのまま3ヶ月（V10失敗）。または申込理由が助言・情報側に偏る（傾聴仮説の反証——これは**成果**として記録し、意思決定伴走型への含意を残す）
- **転換・撤退条件（R3-α系。開始日に確定）**
  - R3-α1（2027-06-30）：非知人・有償・累計10件未満→**有償提供を停止し、βでもγでもなく撤退・再設計を正面の議題にする**（Y-2表：需要ゼロはピボットで救えない）
  - R3-α2（毎月）：代表の実施が宣言上限を超えた月が2回連続→新規予約を絞る（V9の失敗側への栓。件数のために代表を燃やさない）

## 4. 5年の見立て（中央パス・すべて仮定）

| 年 | 起きていること | 件数/年 | 売上 |
|---|---|---|---|
| 2026 | 無償→有償化案内。非知人E3の初件 | 〜30 | 〜3万円 |
| 2027 | 経路2本目。R3-α1判定。認定パートナー募集を**判定後に**開始（順序が命） | 200 | 30万円 |

**儲け指標4つ（見立て）**：①800万円到達＝5年内に未達（代表2先行でも2031年時点で報酬は部分的）②1,000万円＝未達 ③2031年営業利益率＝一桁% ④累積キャッシュ＝百万円未満。**Ver2と同じく「選んで負ける」**。買っているのは速度——需要の真偽が4案で最も早く判明する。
