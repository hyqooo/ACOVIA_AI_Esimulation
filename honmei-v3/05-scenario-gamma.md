# シナリオγ｜単価が先——二階建てを、5年後ではなく2年目に建てる

> **中心のレバー：単価（V1・V7、P-A部品の前倒し合流）。** 15分1,500円の傾聴（変えない）の上に、Ver2 if枠の第1候補P-A「整理の45分」7,700円を、**5.5年後の限界を待たずに2027年から**建てる。生計（段階的専業化・V11）への距離を4案で最も縮めに行く賭け。
> 5年後の見立て（数字はすべて仮定）：15分約1,600件＋45分約400件/年・売上約550万円。**判定（事前の見立て）：唯一「代表2の先行専業化」に構造で応答できる案。ただしVer1の鏡像事故（傾聴を工程に格下げする）に4案でいちばん近く、合流条件とR2-8を最初から背負う**

---

## 1. 起点になった観測（証拠強度つき）

| 観測 | 強度 |
|---|---|
| Ver2本体の帰結：15分単独では通年黒字でも**3名の生計に構造的に届かない**（P-midで2031年に営業利益15万円） | シミュレーション内の構造計算（仮定） |
| Ver2 if枠：P-pivot（2030年に45分導入）でも専業化に届かないが、営業利益は7.7倍差がついた——**導入が遅いほど、単価の階層が効く期間が短い** | 同上 |
| 現実の新事実：**専業化は代表2が先行する可能性が高い**——「3名一括800万円」より手前に、実際の判断点がある | E1（社長の意向表明） |
| Ver1のE3相当の観測：15分→45分の転換率31.2%・「保険の残り回数」場面の再利用38%——**決めどき型の反復需要は、シミュレーション上は一貫して立った** | 仮定（Ver1内の数字） |

**賭けの一文**：この構造が生計を生めないことはVer2が62ヶ月かけて示した。**待っても答えは変わらない。なら、単価の階層を最初から設計に入れ、傾聴の検証を汚さない方法のほうに知恵を使う。**

## 2. 設計（最初の18ヶ月）

| 項目 | 内容 |
|---|---|
| 入口 | 15分傾聴（基本線6点不変）。**入口の約束は「聞くだけ」のまま一字も変えない**（Y-4合流条件1） |
| 上位商品 | 「整理の45分」7,700円。**案内は15分の終了後にも行わない**——申込ページの選択肢としてのみ存在（Y-4条件2：案内は選択肢提示のみ、勧誘なし） |
| 導入時期 | **15分の検証が汚れない順序を守る**：2026年は15分のみ（αと同じ）。45分の公開は**15分の非知人有償E3が成立した後**（2027年上期を仮置き） |
| 担当 | 45分は追加研修合格者のみ（当面は代表——V9の退出はβより遅らせる、と明示的に選ぶ） |
| 動かさない変数 | 時間尺の同時比較はしない（15分と45分は別商品。学びO違反にしない）・V6・録音なし維持 |

## 3. 成功・失敗条件（先に書く）

- **成功**：15分のE3成立**後に**45分が立ち、2028年に45分比率が件数で1〜2割・売上で4〜5割。15分側の「アドバイスされた」指標と30日再利用が**導入前と変わらない**（R2-8が鳴らない）。2029〜30年に**代表2の先行専業化の条件文書が書ける水準**の粗利が見える
- **失敗**：45分が先に立って15分が付け足しになる（Ver1の鏡像事故の再演）。15分利用者の体験指標が悪化する（R2-8発動）。または45分にも需要側E3が来ない——単価の階層は、階段の下段が実在して初めて意味を持つ
- **転換・撤退条件（R3-γ系）**
  - **R2-8（Ver2 if枠の停止条件をそのまま前倒し適用）**：15分の「アドバイスされた」が2四半期連続10%超、または15分の30日再利用が導入前比5pt以上低下×2四半期→**45分の案内を停止**
  - R3-γ1（2027-12-31）：45分の非知人・有償E3が累計5件未満→45分を畳み、αの単線に戻る（撤退ではなく縮退）
  - R3-γ2（随時）：45分の売上を理由に15分の供給・枠を削る決定→無効（K'口①の変種として扱う）

## 4. 5年の見立て（中央パス・すべて仮定）

| 年 | 起きていること | 件数/年（15分/45分） | 売上 |
|---|---|---|---|
| 2026 | αと同一（15分のみ・E3成立を待つ） | 〜30 / 0 | 〜3万円 |
| 2027 | 45分公開。初の45分E3 | 200 / 20 | 45万円 |
| 2028 | 45分が売上の柱に育ち始める | 600 / 120 | 180万円 |
| 2029-31 | 恩送り＋45分担当の追加認定。**2030〜31年に代表2の部分報酬→先行専業化判定** | 1,200→1,600 / 250→400 | 370→550万円 |

**儲け指標4つ（見立て）**：①代表2の800万円到達＝**2031年前後にようやく判定圏**（4案で唯一、5年内に議題化しうる）②1,000万円＝未達 ③2031年営業利益率＝15〜20%（P-pivot実績22.6%を上限の目安に）④累積キャッシュ＝200万円前後。**それでも「3名の」専業化には届かない**——この案が買うのは全員の生計ではなく、**先行1名分の判断材料**である。
