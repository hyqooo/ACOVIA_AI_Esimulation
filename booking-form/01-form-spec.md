## 2. 確認事項（チェックボックスの文面）【既決の4点に対応】

1. 目的を理解しました：経験者がお話を**お聞きする**時間であり、医療相談・カウンセリング・意思決定支援ではないこと
2. 医療に関する助言（治療方針・病院・薬・検査など）は行われないことを理解しました
3. 情報の取扱いを理解しました：予約時にいただくのは呼び名と連絡先のみで、セッションでは品質・安全・運営上の記録だけが残り、会話の全文は記録されないこと
4. 自分の意思で申し込みます。話したくないことは話さなくてよく、途中で休憩・中断・終了でき、参加しなくても不利益がないことを理解しました

注記【要確認】：3.は現行同意文書（「原則録音・録画しない」）に準拠した文面。**録音する運用に切り替える場合は、T-005確定＋同意文書更新後に、次の1文を3.へ差し込む**：
> 「品質と安全の確認のため、セッションの音声を録音すること、録音は（保存期間）のあいだ（保存場所）で保管され、申し出により削除できることを理解しました」——（　）内はT-005の確定値で埋める。**確定前に公開しない。**

## 3. 料金の表示【要確認・有償期のみ】

- 無償期：料金欄を表示しない。冒頭説明に「現在は無料でご案内しています」を追加
- 有償期：**初回30〜45分構造での料金は未決**（15分固定時代の決定は「お試し1,000円→本命1,500円」J-3改）。確定後、冒頭説明と申込確認に同じ金額を表示する。支払方法が未設計のあいだは「お支払い方法はご案内時にお伝えします」とする

## 4. 申込後のフロー【提案】

1. 申込受領の返信（24時間以内目安）→ 日時確定の連絡 → 前日または当日のリマインド（通話手段の案内を含む）
2. 日時確定の連絡に、§0の説明文（医療でないこと・緊急窓口でないこと）を**もう一度**添える
3. 申込内容の控えは連絡手段（メール／LINE）のスレッドに残るものをそのまま使い、**別の台帳に転記しない**（T-005確定まで）
4. セッション実施は `secretary/mvp-first-sessions-guide.md`（開始前チェック・15分の型・Yellow/Red安全フロー・終了後の記録）に従う
