## 2. 設計方針（3行）

1. **個人情報を最小限しか集めない。** T-005（情報保存条件）が未確定のため、本名・治療詳細・病院名は**そもそも入力欄を置かない**（集めなければ保存条件の問題が発生しない）
2. **既決の同意4点と安全案内を、予約の時点で必ず通す。** セッション当日に初めて聞かされる状態を作らない
3. **未決事項（料金・録音・決済）はフォームに書き込まない。** 確定後に差し替えられる形にしてある（`index.html` は冒頭の設定欄1箇所で切替）

## 3. 現フェーズとの対応【既決＋推読】

- 現実の計画：**無償（知人・洗い出し目的・約1ヶ月）→ サポーター2名参加で有償開始**（社長回答 2026-08-06。有償開始「9月上旬ごろ」はこちらの推読であり言明ではない）

- 無償期の申込件数は**需要の証拠に数えない**（R3-0・Stage0-2 §9「需要を測るものではない」）
