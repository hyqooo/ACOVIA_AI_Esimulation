## 0. 新しいフォームを作る

1. https://forms.google.com を開く（ACOVIAで使うGoogleアカウントでログインしておく）
2. 「空白」のフォームを新規作成
3. タイトル：**ACOVIA｜傾聴セッションのご予約**
4. フォームの説明欄に、次をそのまま貼り付ける：

```
不妊治療を経験した対話パートナーが、カメラなしの音声で、あなたのお話をお聞きします。
医療相談・心理療法・カウンセリング・意思決定支援ではありません。治療方針・病院・薬・検査などへの助言は行いません。

現在は無料でご案内しています。

【このフォームは緊急のご相談窓口ではありません】
ご自身や身近な方の安全に差し迫った心配があるときは、次にご連絡ください。
・救急・消防 119／事件・事故 110
・こころの健康相談統一ダイヤル 0570-064-556（お住まいの地域の公的相談機関につながります）
```

> 有償開始後は「現在は無料でご案内しています。」の行を、確定した料金の案内に書き換える（`01-form-spec.md` §3参照。料金は現時点で未決）

## 1. セクション構成（全部で3セクション）

分岐（「2回目以降」を選んだ人だけ長さを聞く）を作るため、セクションを3つに分けます。

| セクション | 内容 |
|---|---|
| セクション1 | 名前・連絡先・利用区分（Q1〜Q3） |
| セクション2 | ご希望の長さ（Q4・「2回目以降」の人だけ通る） |
| セクション3 | 日時希望・ひとこと・同意事項（Q5〜Q7） |

セクションの追加は、右側のツールバーの「セクションを追加」アイコン（田の字に線が入ったアイコン）から行います。

---

## 2. セクション1の質問

### Q1：お呼びする名前
- 種類：**記述式**
- 質問文：`お呼びする名前`
- 説明：`ニックネームで構いません。本名は不要です。`
- 必須：ON

### Q2：ご連絡先
- 種類：**記述式**
- 質問文：`ご連絡先（1つだけ）`
- 説明：`日程のご連絡に使います。メールアドレス、またはLINEでつながっている方は「LINEで」とご記入ください。`
- 必須：ON

### Q3：今回のご利用は（分岐の起点）
- 種類：**ラジオボタン**
- 質問文：`今回のご利用は`
- 選択肢：
  1. `はじめて（30〜45分）`
  2. `2回目以降（15分単位）`
- 必須：ON
- **分岐設定**：右下の「⋮」→「回答に応じてセクションに移動」を有効化
  - 「はじめて（30〜45分）」→ **セクション3に移動**（セクション2＝長さ選択をスキップ）
  - 「2回目以降（15分単位）」→ **セクション2に移動**

---

## 3. セクション2の質問（「2回目以降」の人だけ表示される）

### Q4：ご希望の長さ
- 種類：**ラジオボタン**
- 質問文：`ご希望の長さ`
- 選択肢：`15分` ／ `30分` ／ `45分`
- 必須：OFF（未定でもよいため）
- セクションの下部「次に進む」の設定：**セクション3に進む**

---

## 4. セクション3の質問

### Q5〜Q7：ご希望の日時（3問に分ける）
- 種類：**記述式**（3問とも）
- 質問文：`ご希望の日時・第1希望` ／ `第2希望` ／ `第3希望`
- 説明（第1希望のみ）：`例：8月28日（木）20時以降。時間帯の幅でご記入いただいて構いません。`
- 必須：**第1希望のみON**、第2・第3はOFF

### Q8：お話ししたいことがあれば、ひとことだけ
- 種類：**段落**
- 説明：`書かなくて構いません。詳しい経緯や治療の内容は、ここに書く必要はありません。`
- 必須：OFF

### Q9：確認事項（同意4点）
- 種類：**チェックボックス**
- 質問文：`確認事項（4点すべてにチェックをお願いします）`
- 選択肢（4つとも1問の中に選択肢として入れる）：
  1. `目的を理解しました：経験者がお話をお聞きする時間であり、医療相談・カウンセリング・意思決定支援ではないこと`
  2. `医療に関する助言（治療方針・病院・薬・検査など）は行われないことを理解しました`
  3. `情報の取扱いを理解しました：予約時にいただくのは呼び名と連絡先のみで、セッションでは品質・安全・運営上の記録だけが残り、会話の全文は記録されないこと`
  4. `自分の意思で申し込みます。話したくないことは話さなくてよく、途中で休憩・中断・終了でき、参加しなくても不利益がないことを理解しました`
- 必須：ON
- **「回答の検証」を有効化 → 「選択の最小数」→ 4**（4つ全部にチェックしないと送信できないようにする。これがないと1つだけチェックしても送信できてしまう）

## 5. 「繋がる」ようにするための設定（ここが今回の本題）

1. 右上の設定（歯車アイコン）→「回答」タブ
   - 「回答を1回に制限する」：OFFのままでよい（同じ人が複数回予約する可能性があるため）
2. フォーム編集画面の「回答」タブ → 右上の緑のスプレッドシートアイコン →「新しいスプレッドシートを作成」
   → これで**回答が自動的にスプレッドシートに貯まる**ようになる
3. 同じ「回答」タブ → 右上の「⋮」→ **「新しい回答についてのメール通知を受け取る」をON**
   → **これで、誰かが送信するたびに、ご自身のメールに通知が届く**。「どこにも繋がっていない」状態が、これで解消される
4. 「送信」ボタン →「リンク」アイコンをクリック → URLを短縮してコピー
   → このURLをLINE・メールで知人・メンバー候補に送る

## 6. 送る前の最終確認

- [ ] プレビュー（目のアイコン）で実際に1件テスト送信し、スプレッドシートに反映されることを確認した
- [ ] テスト送信後、通知メールが届くことを確認した
- [ ] 「はじめて」を選んだときにセクション2（長さ選択）が飛ばされることを確認した
- [ ] 「2回目以降」を選んだときにセクション2が表示されることを確認した
- [ ] 同意チェックを3つしか入れずに送信しようとして、エラーで止まることを確認した
- [ ] 料金：無償期は説明文どおりでよい。有償開始時は説明文とQ3の選択肢文言を更新する（`01-form-spec.md` §3）

## 7. `index.html`（単体HTMLフォーム）との使い分け

| 用途 | 使うもの |
|---|---|
| **知人・メンバー候補に配って、自動で回答を貯めたい**（今回の目的） | **このGoogleフォーム** |
| 対面や電話で口頭ヒアリングした内容を、その場で定型文にまとめたいだけ（送信は別途手動） | `index.html`（コピー用の文面生成ツールとして） |

`index.html` は削除していません。今後、Googleフォームでは表現しにくい体験（アニメーション付きの案内など）を作りたくなった場合の下敷きとして残しています。
