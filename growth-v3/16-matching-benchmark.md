# 16｜メンター／マッチング事例の調査と、ACOVIAへの要件化

作成：2026年8月31日／きっかけ：2026-08-31 大谷様トークタイムでの言及（ベネッセ「ウィズバトン」）
**更新：2026年8月31日（同日・夜）** — ネットワーク許可設定の変更により、公式サイト・プレスリリース・インタビュー記事の**原文を取得**。§2-1／§3／§4／§6 を一次情報で書き換えた。

> **証拠強度の現在地**：withbatons については**公式サイト・公式プレスリリース・公式インタビューの原文を確認済み（E3）**。coel・こども家庭庁ピアサポーターの数値は**未確認のまま（E1）**で、§6 に残している。

## 1. 30秒の結論

1. 大谷様が挙げた事例の正式名称は **「withbatons（ウィズバトンズ）」**（ベネッセコーポレーション、2024年6月開始）。記憶されていた「メンター1300人」は、**エントリー数としてはほぼ正確**（約1,200人以上）。ただし**実際に登録・稼働しているメンターは約400人**で、**エントリーの約3分の1**である。ACOVIAが供給を語るときも、この2つを混ぜてはいけない。
2. withbatons の設計で最も重要なのは人数ではなく、**「毎回、異なるメンターと話す」** ことと、**「アルゴリズムが3人を推薦し、その3人の"自由記述"を読んで本人が1人選ぶ」** という半自動マッチングである。**選ばせているのは属性表ではなく、相手の言葉**。ACOVIAの現行方針（運営が全割当・指名なし）と真っ向から異なる。
3. ただし目的が違う。withbatons の中核価値は **代理体験** で、多様な相手に会うほど価値が上がる。ACOVIAのピアサポート型の中核価値は**傾聴**で、多様性は必ずしも価値ではない。**「だから真似しない」で終わらせず、どこまでが目的差で、どこからが我々の思い込みかを分けること**が本メモの主眼（→ §3）。
4. **最大の収穫は、マッチングの設計原理が言語化されていたこと**：「**類似性と新奇性のバランス**」。最初は共感を求めて似た経験の人を望み、「自分もできるかもしれない」と思えると異なるスタイルの人を望むようになる、という**時間軸を持った原理**である。ACOVIAにそのまま移植できる（→ §4-2）。
5. **もう一つの収穫は、商品化に必要だった証拠の規模**：実証研究は**25社・メンティー95名・メンター89名・メンティーは2回のみ**（2023年7〜9月の3ヶ月）。**ACOVIAの90日Gateと同じスケールで商品化に到達している。**
6. 要件化の結論：**条件マッチングは「Phase 2の機能」であり、有償MVP（9月〜）には入れない。** ただし**条件項目の記録だけは初回から取る**。取っていないデータは後から作れない。

## 2. 事例カード

### 2-1. withbatons（ベネッセコーポレーション）｜最も近い構造的類似例

> 出典はすべて一次情報（公式サイト／2024-02-29 公式プレスリリース／『日本の人事部』公式インタビュー・2025年3月）。**以下はすべて E3。**

| 項目 | 内容 |
|---|---|
| 開始 | 2024年6月。ベネッセグループの社内提案制度「**B-STAGE**」から生まれた |
| 対象 | メンティー＝管理職一歩手前層・管理職なりたて層（各社が選出）／メンター＝他社の現役女性リーダー。**年齢のボリュームゾーンは40代女性** |
| セッション | **1回45分**、1対1、オンライン。3〜6ヶ月で**一律6回**（回数は調整不可、頻度は調整可）。**サービス全体は最長8ヶ月** |
| **運営の同席** | **なし**（「※弊社の同席はありません」と公式FAQに明記） |
| 「毎回異なる」の理由 | 公式FAQ：「**できるだけ多くの代理経験を生むため**、最大で6人の価値観や経験が違うメンターと出会う機会を設けております」 |
| マッチングの原理 | **「類似性」と「新奇性」のバランス**。「ほとんどのメンティーは共感を求めてスタートする。最初は自分と似た経験を持つ人の話を聞きたいが、次第に『自分もできるかもしれない』と思えるようになると、自分とは異なるスタイルやアプローチを持つメンターの話を聞きたくなる」 |
| マッチングの入力 | メンター・メンティー**双方**が、仕事内容／働き方／プライベート／仕事の価値観／性格特性のアンケートに回答。**「特に重視しているのは自由記述の部分」**——メンティーは「話したいテーマや関心事」、メンターは「話せるテーマ」を書く |
| マッチングの実装 | **自然言語処理技術を活用したアルゴリズム**。**推薦された3人のメンターの"自由記述"を読み、メンティー自身が1人を選ぶ**。既に管理職の利用者には、**利用者の役職以上の役職**のメンターをあてる |
| メンター規模 | **約400人が登録**（2025年3月時点）。別途「約1,200人以上がエントリー」——**エントリーと登録は別。稼働に至るのは約3分の1** |
| メンターの要件（公式・6項目） | ①女性 ②30代後半〜60代 ③企業・組織で現在**正社員・正規職員として就業中**（フリーランス・個人事業主は不可）④**管理職経験あり** ⑤現在、**従業員数300名以上**の組織に勤務 ⑥後輩女性のキャリアを支援したい気持ちあり。**コーチング等の資格の有無は問わない** |
| メンターの契約 | ベネッセと**面談後に直接、業務委託契約**（2024/06/01〜）。副業可（所属先に副業申請）。**1回45分ごとに謝礼・翌月払い**。平均**月1〜5回**、稼働可能設定は自由に変更でき、繁忙期の**一時的な非稼働設定**も可。**謝礼額は非公開** |
| プログラム全体 | ①キャリア研修 ②アセスメントテスト（これまでのキャリア・現在の就労状況・生活環境・**話したいテーマ**を登録）③社外メンタリング計6回 ④フォローアップ研修 ⑤**企業向けレポート** |
| 記録と振り返り | 毎回のメンタリング後、**メンティーが振り返りをシステムに記録**。**面談後にメンターとメンティーが互いに感謝を伝え合う機会**を設けている。最終研修では「最初に考えていたこと」「6回の記録」「6人から託されたメッセージ」を振り返り、**メンティー同士でインタビューし合いながら言語化** |
| 企業向けレポート | **全部で50枚ほど**。振り返り結果＋サーベイ結果＋満足度＋他社比較。「次年度の施策を検討する際のベースになる」と好評 |
| 契約形態 | 法人契約（企業・団体・組織・部署、単位は問わない）。**メンティー1名から利用可**、人数に応じた料金。**価格は非公開**（サイトは「お見積もり」導線のみ） |
| 実証研究 | **従業員1,000名以上の大手企業25社**が参加。2023年7〜9月、**メンティー95名**（20〜30代管理職手前層）・**メンター89名**（40〜50代）。**メンティーは2回のみ実施**。結果：キャリアの見通しが立った人**＋40%**、管理職への意欲を高めた人**＋18%**、「今の仕事を新たに頑張ってみようと思えた」**8割超**、転職意向も減少 |
| **メンター側の効果** | **メンター側もマネジメントスキル・業務へのモチベーションに好影響**。「相談に乗る女性も相談をする女性も、**『越境の出会い』が現業への意欲を高める**」 |
| 売り方 | メンタリング単体では売っていない。**管理職向け研修・全社セミナーとのパッケージ**（導入事例：大手小売業／大手建設業／大手製造業2社。企業名は非開示） |
| 背景データ | 20〜30代非管理職女性の**87%が「管理職になりたくない」**と回答（自社調査・2022年8月・n=30） |

### 2-2. coel（コエル株式会社）｜不妊治療領域の先行マッチング

- 2016年10月設立、2018年3月に「**日本初、同じ病院に通う妊活仲間を見つけるマッチング・サービス**」を開始。
- 条件項目：**同じ病院**／**同年代・同じ治療段階**（全国）。匿名で悩みを共有。**無料のWebサービス**。
- **現況は依然として未確認（E1）**。本日 `coeljapan.com` へ複数回アクセスを試みたが**応答なし**（DNS解決せず／プロキシが502を返す）。ただし**Wayback Machineに2026年6月13日付のスナップショット（status 200）が存在する**ため、「2ヶ月半前までは生きていた」以上のことは言えない。**サイトの死活と事業の死活は別**なので、断定しない。
- ACOVIAにとっての意味：**我々が「新しい」と思っている条件マッチングは、8年前に無料で提供されている**。差分は「つながる場」を作ることではなく、**1対1で決まった時間に必ず聞いてもらえること**にある、という仮説を強める材料。

### 2-3. Progyny／Maven Clinic（米国・企業原資型）

| | Progyny | Maven Clinic |
|---|---|---|
| 担当のつけ方 | 加入時点で**専任のPatient Care Advocate（PCA）を1名ペアリング**。不妊治療・家族形成のゴールに基づいて割当 | オンボーディングのassessment＋Care Advocateとの会話で**個別ケアプラン**を作成 |
| 担当者の属性 | 看護師、ドゥーラ、代理出産・養子縁組コーチ等の**有資格・専門職** | Care Advocate＋専門職ネットワーク |
| 運用の特徴 | 臨床と統合された1対1の伴走。専門職への接続を担当が行う | **プロアクティブなチェックイン**（本人からの申告を待たない）。所在地・ニーズ・希望でprovider matching |

> **示唆**：米国の勝ち筋は「経験者マッチング」ではなく**「専任の専門職伴走者」**。ACOVIAが経験者ピアで勝負するなら、**専門職に対する優位を1文で言えること**が要件になる（大谷様の言葉「同じように落ち込んだっていうところを知ってくださってるから、余計に説得力があって」が現時点の最有力）。

### 2-4. cotree（オンラインカウンセリング）｜供給側の品質担保

- 登録カウンセラーの**半数以上が臨床心理士・公認心理師**。登録要件として **実務経験3年・セッション実績100件以上**を課している。
- マッチング診断（性格タイプ・相談内容・希望）で紹介する方式。
- **示唆**：ACOVIAのサポーターは資格を要件にできない（経験者であることが要件）。**代わりに何を「通過基準」にするかを、cotreeの2条件と同じ粒度で書けるか**が問われる。現状は研修・ロールプレイ8ケース・評価という設計まではあるが、**通過ラインの数値がない**。

### 2-5. こども家庭庁 不妊症・不育症ピアサポーター｜供給プールの規模

- 2021年度（厚労省）開始、現在はこども家庭庁委託事業として日本助産師会が実施。
- **3,306名**が認定され、性と健康の相談センター・都道府県助産師会を通じて活動（**時点の記載が確認できず。要確認**）。
- **示唆**：`growth-v3/04` で「認定修了者の約5%＝推定160名前後が男性サポーターの主な供給源」としていた推定の分母がこれに当たる。**分母の時点と定義を確定させないと、供給計画の数字が動く。**

### 2-6. がん領域のピアサポート（5years／Peer Ring）｜運用リスクの先行知見

- コミュニティ型SNSが中心。運営はパトロールとコミュニケーション支援を行っている。
- 一般に指摘されている運用リスク：**他者の体験談を聞いて自身の辛い経験が想起され体調が悪化する**／**似た状況でも事情や症状に差があり、比較して落ち込む**。対策として**専門家のファシリテート**と**何かあったときに相談できる体制**が重要とされる。
- **示唆**：ピアサポート型仮説の失敗パターン⑥「相談者とサポーターの経験差が比較・傷つきにつながる」は、**我々の想像ではなく他領域で観測済みのリスク**。マッチング条件の設計は、この一点だけでも正当化される。

## 3. withbatonsから抜き出せる5つの設計判断

| # | 彼らの判断 | ACOVIAはどうか | 目的差か、思い込みか |
|---|---|---|---|
| 1 | **毎回異なる相手**にする | 現行方針は運営割当・指名なし（＝相手が変わるかは未定義） | **目的差**。代理体験の最大化はACOVIAの中核ではない。ただし**「同じ人に続けて聞いてもらえるか」は未決のまま**であり、決めていないことを決めた扱いにしない |
| 2 | **AIが3名の候補→本人が選ぶ**（全自動でも全割当でもない） | 現行は全割当 | **思い込みの可能性**。全割当を選んだ理由は「指名は運用が重い」だったが、**3択提示なら運用は重くならない**。9/6以降の再検討候補 |
| 3 | マッチングで**最重視するのは自由記述**（構造化項目ではない）。**選ばせるのも自由記述** | 条件項目そのものが未定義 | **思い込みの是正**。我々は「条件マッチング＝属性の一致」と考えていたが、彼らは属性を入口にしつつ、**決め手を相手の言葉に置いている**。ACOVIAの§4-1もA群を選択式で固めすぎない |
| 4 | メンターは**業務委託・回数ごとの謝礼・翌月払い・月1〜5回**。**繁忙期の一時的な非稼働設定ができる** | サポーター報酬は未確定 | **そのまま比較対象**。「月1〜5回」は**善意依存を避けつつ生活の柱にもしない**水準。**非稼働設定の仕組み**は、失敗パターン⑤（善意依存で疲弊）への具体的な答えであり、今日から真似できる |
| 5 | メンター獲得に **ATSを導入**＝採用業務として運用。ただし**エントリー約1,200に対し登録は約400（約3分の1）** | 現在2名。募集は後回しの方針 | **歩留まりの学び**。「募集すれば集まる」ではない。`sim-v3.5` L15（供給は需要に3ヶ月遅れる）の根拠が一つ増えた |
| 6 | **運営は同席しない** | 品質は「見る人」で担保する設計（L14） | **正面から対立**。彼らは同席の代わりに、**入口条件の明文化・毎回相手を変える・振り返りのシステム記録・50枚のレポート**で担保している。**ACOVIAが同席を選ぶなら、それはコストであって当然ではない**——「なぜ同席するのか」を1文で言えるようにする |
| 7 | **メンター側にも効果が出た**（マネジメントスキル・現業への意欲） | サポーターの参加動機は未設計 | **最大の拾いもの**。参加動機を「善意」ではなく「**自分にも効く**」に置ける。失敗パターン⑤への構造的な答え。ただしACOVIAの傾聴で同じ効果が出るかは**未検証**（傾聴は代理体験と違い、聞き手が得るものが自明でない） |

## 4. ACOVIAへの要件化（準備物）

### 4-1. 条件設定：初回から記録する項目（v0）

> 原則：**マッチングに使うかどうかと、記録するかどうかは別**。使わなくても記録する。使いたくなったときに遡れないため。
> 大谷様の証言から導いた設計原理：一致させるべきは**属性ではなく「落ち込みの経験」**（「同じように落ち込んだっていうところを知ってくださってるから、余計に説得力があって」）。

**A群：ほぼ確実に効く（初回から取る・同意の上で）**

| 項目 | 選択肢の例 | 根拠 |
|---|---|---|
| 治療のフェーズ | 検査中／タイミング法・人工授精／体外受精中／移植待ち／結果待ち／休止中／終結を考えている | 急性トリガー仮説の中核 |
| 直近の出来事 | 判定日の結果／採卵・移植の結果／転院の検討／保険適用の残り／医師の説明への戸惑い／特になし | 「利用の瞬間」の観測 |
| 今日ほしいもの | ただ聞いてほしい／整理したい／経験を聞きたい／決めたいことがある | **傾聴と伴走の分岐点。混ぜて測らない（Gate②）** |
| 話したくないこと | 自由記述（例：他人の妊娠報告、年齢、夫のこと） | **地雷の事前回避。これは今日から取れる** |

**B群：効きそうだが未検証（記録はする・マッチングには使わない）**

治療年数／体外受精の回数／年齢帯／就労状況（就業中・休職・退職）／パートナーの関与度／居住地域／通院先の種別（都市部の大規模／地方）／子どもの有無を話題にしてよいか

**C群：取らない／取るなら明確な理由が要る**

医療機関名（coelは「同じ病院」を条件にしたが、ACOVIAは**中立性のため紹介・送客をしない**方針＝K'-3。病院名を持つと誘導の疑いを招く）／診断名・検査値（医療情報になる）／収入

### 4-2. マッチング：3段階で上げる

| Phase | 時期 | 方式 | 決めること |
|---|---|---|---|
| **P0** | **9月〜（有償MVP前後）** | **全割当**（現行方針を維持）。ただし**A群4項目を予約時に取得し、サポーターに事前共有** | 事前共有の様式（1枚）。「話したくないこと」の扱い |
| **P1** | 供給が5名を超えた時点 | **運営が手で2〜3名の候補に絞り、本人が選ぶ**（withbatonsの3択提示の低コスト版） | 絞り込みのルールを文章で固定してから運用する（後付けにしない） |
| **P2** | 法人契約が始まってから | 条件入力＋半自動の候補提示 | A群・B群の中から、実データで効いた項目だけを残す |

**「類似性」と「新奇性」——ACOVIAへの移植（withbatonsからの最大の学び）**

彼らの原理は「最初は共感（類似性）を求め、力がついてくると異なる視点（新奇性）を求める」という**時間軸を持ったもの**である。ACOVIAへの移植は次のようになる。

- **ACOVIAは初回で終わる可能性が高いので、まず類似性に全振りする。** 治療フェーズ・直近の出来事が近い人をあてる。新奇性は当面いらない。
- ただし**類似性の中身が違う**。彼らの類似性は「キャリアの状況」だが、大谷様の証言が示したACOVIAの類似性は「**同じように落ち込んだことを知っている**」——**状況ではなく感情の経験**である。一致させるのは属性ではない。
- 新奇性が意味を持つとすれば**再利用のとき**（2回目以降に「別の道を選んだ人の話も聞いてみたい」が出るか）。**これは観測項目であって、初期設計に入れない。**

**P0で決めておくべき例外（今日書ける）**
- 同一サポーターの**再指名を認めるか**（大谷様の「LINEの先輩」は同一人物の継続関係。ACOVIAが毎回別人にすると、証言された価値と逆をやることになる）→ **推奨：「同じ人を希望できる。ただし保証はしない」**
- **経験差による傷つきの回避**：結果が出た人／出なかった人のどちらをあてるか。**「終結を考えている人に、出産に至った経験者をあてない」を初期ルールとして明文化**（がん領域の知見・失敗パターン⑥）
- **不成立時の代替**：候補がいない場合に「今日は枠がない」と言うのか、別日を出すのか

### 4-3. 運用：withbatonsとの差分で必要になるもの

| 論点 | withbatons | ACOVIAの要件（案） |
|---|---|---|

## 5. これは決めないと先に進めない（論点）

1. **同じサポーターを続けて選べるか。** withbatonsは意図的に毎回変える。大谷様の証言が示した価値は継続関係（「LINEの先輩」）。**ACOVIAはどちらか。**
2. **全割当を続けるか、3択提示に変えるか。** 全割当を選んだ理由が「運用が重いから」だとすれば、その理由は3択提示には当てはまらない。**しかも提示すべきは属性表ではなくサポーターの言葉**（§3-3）。
3. **サポーターの通過ラインを数値で書けるか。** withbatonsは6項目で書いており、**うち5項目は事実で判定でき、能力評価はゼロ、資格も問わない**。書けないなら品質は属人的なまま（失敗パターン⑥）。
4. **運営は同席するのか、しないのか。** withbatonsは同席しない。ACOVIAは「見る人が要る」（L14）。**どちらが正しいかではなく、同席を選ぶならその理由を1文で言えるか**が問われる。
5. **coelは今どうなっているか。** 生きているなら競合、畳んでいるなら「無料では続かない」の証拠。**どちらでも我々の意思決定に効く。**

### 参考：商品化に必要だった証拠の規模

**withbatonsの実証研究は、25社・メンティー95名・メンター89名・メンティーは2回のみ・期間3ヶ月（2023年7〜9月）だった。** そこから得た数字（キャリアの見通しが立った人＋40%、管理職意欲＋18%、8割超が前向きに）を根拠に、翌年6月から商品化している。

**これはACOVIAの90日Gate（2026年8月3日〜10月31日）とほぼ同じスケールである。** 大企業が1年の実証と言っても、実体はこの規模であり、**「証拠が足りないから売れない」のではなく「測る設計がないから売れない」**ことを示している。

ただし条件が2つある。①**参加企業を25社集めた**（無償の実証でも、法人が入っていた）②**前後比較の設問を最初から用意していた**。ACOVIAのGate②（顧客成果）は、この2点を満たす形になっているか——**明日の定例で確認する価値がある。**
