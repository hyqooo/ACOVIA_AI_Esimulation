## 1. 30秒の結論

1. 大谷様が挙げた事例の正式名称は **「withbatons（ウィズバトンズ）」**（ベネッセコーポレーション、2024年6月開始）。記憶されていた「メンター1300人」は **「約1,200人以上がエントリー」** とほぼ一致しており、**証言は正確**だった。
2. withbatons の設計で最も重要なのは人数ではなく、**「毎回、異なるメンターと話す」** という選択と、**「AIが3人の候補を出し、最後はメンティー本人が選ぶ」** という半自動マッチングである。ACOVIAの現行方針（相談員は運営側で割当・指名なし）と**真っ向から異なる**。
3. ただし目的が違う。withbatons の中核価値は **代理体験（自分と近い他者の生き方を借りて見る）** であり、多様な相手に会うほど価値が上がる。ACOVIAのピアサポート型の中核価値は**傾聴**で、多様性は必ずしも価値ではない。**「だから真似しない」で終わらせず、どこまでが目的差で、どこからが我々の思い込みかを分けること**が本メモの主眼。
4. 不妊治療領域には既に **coel（コエル）** という「同じ病院に通う妊活仲間のマッチング」の先行例が2018年から存在する（**無料**）。**失敗パターン①「需要はあるが無料でしか使われない」の実例になりうる**ため、現況の確認は優先度が高い。
5. 要件化の結論：**条件マッチングは「Phase 2の機能」であり、有償MVP（9月〜）には入れない。** ただし**条件項目の記録だけは初回から取る**。取っていないデータは後から作れない。

## 2. 事例カード

### 2-1. withbatons（ベネッセコーポレーション）｜最も近い構造的類似例

| 項目 | 内容 | 強度 |
|---|---|---|
| 開始 | 2024年6月（試行はそれ以前） | E2 |
| 対象 | メンティー＝20〜30代の女性社員（管理職候補）／メンター＝他社の現役女性リーダー（30代後半〜50代） | E1 |
| セッション | **1回45分**。3〜6ヶ月で**計6回**。**毎回、異なるメンター** | E2 |
| 「毎回異なる」の理由 | **代理体験をできるだけ多く生むため**。異なる価値観・経験を持つ最大6名に出会える | E1 |
| マッチング | 自社開発のAIアルゴリズム。当初**3,000項目以上**を作り、約1年かけて**約60項目**に絞り込んだ。**毎回AIが3名の候補を提示し、メンティーが最終的に1名を選ぶ** | E1 |
| メンター規模 | **約1,200人以上がエントリー**（別の記述では「約400人」「3,500人以上」もあり、**時点と定義が不一致。要確認**） | E1 |
| メンターの契約 | **業務委託契約**。1回45分ごとに謝礼（**翌月払い**）。平均**月1〜5回**の稼働。マッチング成立件数により変動 | E2 |
| メンター採用 | 採用管理システム **sonar ATS** を導入。**メンター獲得を「採用業務」として運用している** | E1 |
| プログラム全体 | ①キャリア研修 ②サーベイ診断 ③社外メンタリング6回 ④事後研修 ⑤**企業へのレポート** | E1 |
| 契約形態 | 法人契約（企業・団体・部門単位）。**メンティー1名から導入可**、人数に応じた価格設定。**価格は非公開** | E1 |
| 実績 | 試行段階で**8割以上**がモチベーション・管理職昇格意欲が向上。2024年度グッドデザイン賞受賞 | E1 |

### 2-2. coel（コエル株式会社）｜不妊治療領域の先行マッチング

- 2016年10月設立、2018年3月に「**日本初、同じ病院に通う妊活仲間を見つけるマッチング・サービス**」を開始。
- 条件項目：**同じ病院**／**同年代・同じ治療段階**（全国）。匿名で悩みを共有。**無料のWebサービス**。
- **現況は未確認**（2021年時点で稼働の記録あり）。**要確認**。
- ACOVIAにとっての意味：**我々が「新しい」と思っている条件マッチングは、8年前に無料で提供されている**。差分は「つながる場」を作ることではなく、**1対1で決まった時間に必ず聞いてもらえること**にある、という仮説を強める材料。

### 2-3. Progyny／Maven Clinic（米国・企業原資型）

| | Progyny | Maven Clinic |
|---|---|---|
| 担当のつけ方 | 加入時点で**専任のPatient Care Advocate（PCA）を1名ペアリング**。不妊治療・家族形成のゴールに基づいて割当 | オンボーディングのassessment＋Care Advocateとの会話で**個別ケアプラン**を作成 |
| 担当者の属性 | 看護師、ドゥーラ、代理出産・養子縁組コーチ等の**有資格・専門職** | Care Advocate＋専門職ネットワーク |
| 運用の特徴 | 臨床と統合された1対1の伴走。専門職への接続を担当が行う | **プロアクティブなチェックイン**（本人からの申告を待たない）。所在地・ニーズ・希望でprovider matching |

> **示唆**：米国の勝ち筋は「経験者マッチング」ではなく**「専任の専門職伴走者」**。ACOVIAが経験者ピアで勝負するなら、**専門職に対する優位を1文で言えること**が要件になる（大谷様の言葉「同じように落ち込んだっていうところを知ってくださってるから、余計に説得力があって」が現時点の最有力）。

### 2-4. cotree（オンラインカウンセリング）｜供給側の品質担保

- 登録カウンセラーの**半数以上が臨床心理士・公認心理師**。登録要件として **実務経験3年・セッション実績100件以上**を課している。
- マッチング診断（性格タイプ・相談内容・希望）で紹介する方式。
- **示唆**：ACOVIAのサポーターは資格を要件にできない（経験者であることが要件）。**代わりに何を「通過基準」にするかを、cotreeの2条件と同じ粒度で書けるか**が問われる。現状は研修・ロールプレイ8ケース・評価という設計まではあるが、**通過ラインの数値がない**。

### 2-5. こども家庭庁 不妊症・不育症ピアサポーター｜供給プールの規模

- 2021年度（厚労省）開始、現在はこども家庭庁委託事業として日本助産師会が実施。
- **3,306名**が認定され、性と健康の相談センター・都道府県助産師会を通じて活動（**時点の記載が確認できず。要確認**）。
- **示唆**：`growth-v3/04` で「認定修了者の約5%＝推定160名前後が男性サポーターの主な供給源」としていた推定の分母がこれに当たる。**分母の時点と定義を確定させないと、供給計画の数字が動く。**

### 2-6. がん領域のピアサポート（5years／Peer Ring）｜運用リスクの先行知見

- コミュニティ型SNSが中心。運営はパトロールとコミュニケーション支援を行っている。
- 一般に指摘されている運用リスク：**他者の体験談を聞いて自身の辛い経験が想起され体調が悪化する**／**似た状況でも事情や症状に差があり、比較して落ち込む**。対策として**専門家のファシリテート**と**何かあったときに相談できる体制**が重要とされる。
- **示唆**：ピアサポート型仮説の失敗パターン⑥「相談者とサポーターの経験差が比較・傷つきにつながる」は、**我々の想像ではなく他領域で観測済みのリスク**。マッチング条件の設計は、この一点だけでも正当化される。

## 3. withbatonsから抜き出せる5つの設計判断

| # | 彼らの判断 | ACOVIAはどうか | 目的差か、思い込みか |
|---|---|---|---|
| 1 | **毎回異なる相手**にする | 現行方針は運営割当・指名なし（＝相手が変わるかは未定義） | **目的差**。代理体験の最大化はACOVIAの中核ではない。ただし**「同じ人に続けて聞いてもらえるか」は未決のまま**であり、決めていないことを決めた扱いにしない |
| 2 | **AIが3名の候補→本人が選ぶ**（全自動でも全割当でもない） | 現行は全割当 | **思い込みの可能性**。全割当を選んだ理由は「指名は運用が重い」だったが、**3択提示なら運用は重くならない**。9/6以降の再検討候補 |
| 3 | 条件項目を **3,000超→約60に絞った**（1年かけて） | 条件項目そのものが未定義 | **手順の学び**。最初から60項目を当てにいかず、**広く取って削る**。だから**初回から記録だけは取る**（§4-1） |
| 4 | メンターは**業務委託・回数ごとの謝礼・翌月払い・月1〜5回** | サポーター報酬は未確定 | **そのまま比較対象**。「月1〜5回」は**善意依存を避けつつ生活の柱にもしない**水準であり、失敗パターン⑤への一つの答え |
| 5 | メンター獲得に **ATSを導入**＝採用業務として運用 | 現在2名。募集は後回しの方針 | **時期の学び**。人数を増やす前に、**「採ってから使う」ではなく「使う分だけ採る」運用**を先に持つ（`sim-v3.5` L15：供給は需要に3ヶ月遅れる） |

## 4. ACOVIAへの要件化（準備物）

### 4-1. 条件設定：初回から記録する項目（v0）

> 原則：**マッチングに使うかどうかと、記録するかどうかは別**。使わなくても記録する。使いたくなったときに遡れないため。
> 大谷様の証言から導いた設計原理：一致させるべきは**属性ではなく「落ち込みの経験」**（「同じように落ち込んだっていうところを知ってくださってるから、余計に説得力があって」）。

**A群：ほぼ確実に効く（初回から取る・同意の上で）**

| 項目 | 選択肢の例 | 根拠 |
|---|---|---|
| 治療のフェーズ | 検査中／タイミング法・人工授精／体外受精中／移植待ち／結果待ち／休止中／終結を考えている | 急性トリガー仮説の中核 |
| 直近の出来事 | 判定日の結果／採卵・移植の結果／転院の検討／保険適用の残り／医師の説明への戸惑い／特になし | 「利用の瞬間」の観測 |
| 今日ほしいもの | ただ聞いてほしい／整理したい／経験を聞きたい／決めたいことがある | **傾聴と伴走の分岐点。混ぜて測らない（Gate②）** |
| 話したくないこと | 自由記述（例：他人の妊娠報告、年齢、夫のこと） | **地雷の事前回避。これは今日から取れる** |

**B群：効きそうだが未検証（記録はする・マッチングには使わない）**

治療年数／体外受精の回数／年齢帯／就労状況（就業中・休職・退職）／パートナーの関与度／居住地域／通院先の種別（都市部の大規模／地方）／子どもの有無を話題にしてよいか

**C群：取らない／取るなら明確な理由が要る**

医療機関名（coelは「同じ病院」を条件にしたが、ACOVIAは**中立性のため紹介・送客をしない**方針＝K'-3。病院名を持つと誘導の疑いを招く）／診断名・検査値（医療情報になる）／収入

### 4-2. マッチング：3段階で上げる

| Phase | 時期 | 方式 | 決めること |
|---|---|---|---|
| **P0** | **9月〜（有償MVP前後）** | **全割当**（現行方針を維持）。ただし**A群4項目を予約時に取得し、サポーターに事前共有** | 事前共有の様式（1枚）。「話したくないこと」の扱い |
| **P1** | 供給が5名を超えた時点 | **運営が手で2〜3名の候補に絞り、本人が選ぶ**（withbatonsの3択提示の低コスト版） | 絞り込みのルールを文章で固定してから運用する（後付けにしない） |
| **P2** | 法人契約が始まってから | 条件入力＋半自動の候補提示 | A群・B群の中から、実データで効いた項目だけを残す（3,000→60と同じ手順の縮小版） |

**P0で決めておくべき例外（今日書ける）**
- 同一サポーターの**再指名を認めるか**（大谷様の「LINEの先輩」は同一人物の継続関係。ACOVIAが毎回別人にすると、証言された価値と逆をやることになる）→ **推奨：「同じ人を希望できる。ただし保証はしない」**
- **経験差による傷つきの回避**：結果が出た人／出なかった人のどちらをあてるか。**「終結を考えている人に、出産に至った経験者をあてない」を初期ルールとして明文化**（がん領域の知見・失敗パターン⑥）
- **不成立時の代替**：候補がいない場合に「今日は枠がない」と言うのか、別日を出すのか

### 4-3. 運用：withbatonsとの差分で必要になるもの

| 論点 | withbatons | ACOVIAの要件（案） |
|---|---|---|
| 時間 | 45分×6回 | **15分固定**。**終わり方の型が別途必要**（8/31は約48分超過。15分では終わらせる技術が要る） |
| 事前案内 | 研修・サーベイが前段にある | **案内文1枚**（目的／所要時間／録音の有無と保存期間／答えたくないことは飛ばせる）。8/31は「これって県プロなんでしたっけ？」から始まった |
| 品質担保 | 事後研修＋企業レポート | 研修・ロールプレイ8ケース・評価はあるが**通過ラインの数値がない**。cotree の「実務経験3年・100件以上」と同じ粒度で書く |
| 危機対応 | （記載を確認できず） | **ACOVIA固有の必須要件**。レッドフラグの分岐を文言として確定（8/31の議論メモ §2） |
| 供給の増やし方 | ATSで採用業務化 | **3ヶ月先の必要数から逆算して募集**（`sim-v3.5` L15）。人数ではなく**「今週何枠出せるか」**を管理単位にする |
| 報酬 | 回数ごとの謝礼・翌月払い・月1〜5回 | 未確定。**「月1〜5回」を上限の目安として設計**（善意依存も生活依存も避ける） |

## 5. これは決めないと先に進めない（論点）

1. **同じサポーターを続けて選べるか。** withbatonsは意図的に毎回変える。大谷様の証言が示した価値は継続関係。**ACOVIAはどちらか。**
2. **全割当を続けるか、3択提示に変えるか。** 全割当を選んだ理由が「運用が重いから」だとすれば、その理由は3択提示には当てはまらない。
3. **サポーターの通過ラインを数値で書けるか。** 書けないなら、品質は属人的なまま（失敗パターン⑥）。
4. **coelは今どうなっているか。** 生きているなら競合、畳んでいるなら「無料では続かない」の証拠。**どちらでも我々の意思決定に効く。**
