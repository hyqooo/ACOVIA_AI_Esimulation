# 04｜事業モデル：三層構造で10億円とミッションを両立させる

作成：2026年8月27日／ACOVIA AI経営チーム（CEO・CPO・CFO・CMO合議）

> **数字はすべて仮定。** 単価・件数は`05`の感度表とセットで読むこと。

---

## 1. 全体像：検証エンジン × スケールエンジン × 独自性エンジン

```
第1層｜C向け直販（検証・品質エンジン）────────── 売上構成 ~10%
  経験者との構造化対話（傾聴→伴走の2階建て）＋Decision Note
  役割：E3証拠の生産、体験品質の基準器、サポーター訓練の場
  ※単独でスケールさせない（Ver3感度分析の教訓）

第2層｜B2B2E/B2B2C 契約（スケールエンジン）───── 売上構成 ~75%
  企業：福利厚生・両立支援プログラム「ACOVIA for Work（仮）」
  クリニック：患者向け意思決定サポート「ACOVIA for Clinic（仮）」
  自治体：相談事業の運営受託・ピアサポーター稼働提供
  役割：10億円の主柱。沈黙の均衡へのL4介入そのもの

第3層｜型の資産化（独自性・拡張エンジン）─────── 売上構成 ~15%
  サポーター研修・認定プログラム（受け皿事業）
  ゴール設計（終わりの設計）プログラム
  Stage2 AI（サポーター支援・Note生成支援）→ 粗利改善装置
  第2ドメイン展開（Year4〜）：介護・がん治療の意思決定
```

## 2. 第2層の中身（主柱の設計）

### 2-1. ACOVIA for Work（企業向け）

| 項目 | 内容 |
|---|---|
| 提供物 | ①従業員・配偶者が使えるセッション枠（匿名利用可）②管理職向け研修（年1〜2回）③制度設計支援（休暇制度・就業規則の整備支援→両立支援等助成金 最大90万円の申請と接続）④集団統計レポート（年2回） |
| 価格モデル | 従業員規模別の年額固定＋利用従量。目安：〜300名 60万円/年、〜2,000名 240万円/年、それ以上 600万円/年〜 |
| 導入の言い分 | 「不妊治療を理由に、両立をあきらめる人が26.1%いる。開示率5割未満だから人事はニーズを観測できない。**観測できないニーズは、制度を先に置くしか拾えない**」 |
| 政策接続 | 両立支援等助成金（不妊治療及び女性の健康課題対応両立支援コース）・くるみんプラス認定の取得支援をセットにする。**導入コストの一部を国が持つ構造** |
| 差別化 | (a)経験者ピア（専門職監修つき）による対話、(b)**男性従業員・パートナーも対象**、(c)Decision Noteという成果物、(d)意思決定葛藤の前後測定を出せる |
| 先行事例 | ファミワン（小田急・ミクシィ等に導入実績、看護師等の専門家相談中心）。米国ではProgynyがFY2025売上$1.29B（約1,900億円）・Maven/Carrot等ユニコーン級——**「不妊×雇用主」は世界で最も大きく育った収益モデル**であり、日本は制度追い風があるのにほぼ空白 |

### 2-2. ACOVIA for Clinic（クリニック向け）

- 提供物：治療開始時の「ゴール設計セッション」、転院・ステップアップ・終結局面の意思決定サポート、待合改善（心理的サポートの外部化）
- 価格：月額8〜15万円＋患者利用従量（クリニック負担 or 患者半額負担のハイブリッド）
- クリニックの言い分：患者満足・口コミ差別化・通院継続。**紹介料は取らない**（K'-3の栓維持：ACOVIAはどのクリニックが良いかの誘導を一切しない。だから中立でいられる）
- リスク：医療機関の財布は固い。FY2027に2件のパイロットで支払意思を検証してから本格化（反証条件は`07`のゲート）

### 2-3. 自治体（FY2028から）

- 性と健康の相談センター等のピア相談運営受託・サポーター派遣。単価目安300〜600万円/年
- 意義：地域格差（大阪府延べ3,498件 vs 鳥取県5年で326件）の平準化。**入札・委託の商流調査が前提**（Notion調査の「今後の調査候補」を先に潰す）

## 3. 第1層：C向けの位置づけを変える

- 傾聴15分（ピアサポート型仮説）と伴走25〜30分（意思決定伴走型仮説）を**1つの動線に積層**：急性の感情トリガー（悪い結果の当日〜翌日）は傾聴枠で受け、落ち着いた時点で伴走枠とDecision Noteへ
- 価格は中核帯を維持（30分3,000〜5,000円。Ver3感度分析の結論を踏襲）。**C向け単体の黒字化を目標にしない**——法人契約のショーケースであり、サポーターの練度形成の場であり、E3証拠の源泉
- 2つの仮説のどちらが本命か、という積年の論点への v3の答え：**法人経由では両方売る。傾聴は入口、意思決定は成果。** 検証上は引き続き別々に測る（Gate②の測定を混ぜない）

## 5. 競争優位（VC質疑「なぜ勝てるか」への答え）

1. **供給ネットワークの先行独占**：公式名簿が存在しないため、修了者への一斉アプローチは誰にも出来ない。ACOVIAが研修・評価・報酬・保険（賠償責任）・SVを備えた**唯一の有償受け皿**になれば、後発は供給から作り直すしかない。供給の質はマニュアルでなく稼働時間で蓄積する
2. **Decision Noteと問いの体系**：セッションごとに蓄積する「局面×問い×次の一歩」の構造化データ（匿名化・同意ベース）。Stage2 AIの学習資産であり、第2ドメイン移植の中身そのもの
3. **中立性**：クリニック紹介料を取らない・治療継続にも終結にも肩入れしない。**企業とも本人の側に立つ契約**（`01`§4）。この中立性は収益構造の設計でしか作れず、後発の医療系・人材系プレイヤーには構造的に模倣しにくい
4. **測れる成果**：意思決定葛藤の前後測定を最初から装備。「満足度が高い」ではなく「葛藤が下がり行動が起きた」を企業に報告できる

## 6. 領域拡張（条件6）：Year4からの第2ドメイン

- 判断時点：**FY2029末**（不妊治療ドメインでM1〜M5の中間アウトカムがE3以上で揃っていることが条件。揃わなければ拡張しない——失敗パターン11「壮大な構想に引っ張られる」の栓）
- 第1候補：**介護の意思決定**（施設入居・在宅・看取り。企業の両立支援ニーズが不妊治療と同型で、**同じ人事部に同じ契約形態で売れる**——チャネル再利用が効く）。第2候補：がん治療と仕事の両立
- 移植するもの：問いの体系・Decision Note・サポーター研修の型・法人契約のオペレーション。移植しないもの：不妊治療の経験者ネットワークそのもの（ドメインごとに経験者を新規に組成する）
- FY2030にパイロット5社（既存顧客のクロスセル）、FY2031に売上0.5億円規模を仮置き（`05`）

## 7. やらないこと（v3でも維持する歯止め）

- 保険会社への営業／病院システム連携／24時間即時対応／独自AIモデル開発／不特定多数への啓蒙事業（LP-1）／クリニック紹介・送客ビジネス／治療終了支援の単独サービス化（中核に内蔵はする）
- 同時に走らせる事業は**最大2層まで**（FY2027は第1層＋Work。Clinicパイロットは2件のみ。自治体はFY2028まで凍結）
