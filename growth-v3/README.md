## 30秒でわかる結論

1. **6条件は、C向けセッションの単線では数学的に満たせない**（Ver3感度分析より）。v3は**部分ピボット**を提案する：支払者を本人から企業・クリニック・自治体へ移す**B2B2E中心の三層モデル**。セッションの中身・傾聴と伴走の積層・本人が主語であることは変えない
2. **レバレッジは3点セット**：構造図v7の5ループのうち「沈黙の均衡」をL4（制度を先に置く＝法人契約）で断つのが主エンジン、「承認役の固定」をL3（夫婦・男性設計）で断つのが差別化、「サンクコスト」をL5（終わりの設計）で断つのが独自性。**需要側のループ切断と、供給側の空白（認定ピアサポーター3,306名 vs 稼働枠二桁未満）を1つのモデルで同時に埋める**——これがToCの背骨であり、KIBOW賞の勝ち筋
3. **10億円（FY2031）の分解**：企業250社×240万=6.0億＋クリニック100院1.2億＋自治体0.9億＋C向け1.0億＋研修0.4億＋第2ドメイン0.5億。外部照合：米Progynyが同型モデルで売上$1.29B（FY2025）、日本は助成金・くるみんプラスの追い風があるのに空白
4. **報酬2,000万×2名（FY2029）は成立するが、シリーズA交渉の弾を消費する**。業績連動込み・事前明記で設計し、売上ゲート（FY2029に2.5億）不達なら報酬目標も自動後退させる
5. **男性ペイン**は独立事業にせず標準装備にする：Decision Noteの夫婦共有設計／法人契約の男性枠（本人・パートナーとも）／男性経験者サポーター育成（認定修了者の約5%≒160名が supply）／泌尿器科受診前の問いの整理
6. **上書きが必要な既存決定が8つある**（VC非前提・G見送り・専業化順序など）。全て`01`§3に明示し、社長判断待ち。**最初の締切は2026-09-15の応募仮決め**、エントリーは11/2〜15、本選は2027-02-14
7. **鍛えた結果、残った最大の急所**：①企業の予算化（E0、2027-06までに判明）②制度を置いても使われないリスク（利用率3%ゲート）③FY2028の5→25社ジャンプ。すべてKill条件つき。外れたら10億線を降りて憲法の持続型（選択肢2）へ回帰する——**受賞と10億は目標だが、ミッションは制約である**
