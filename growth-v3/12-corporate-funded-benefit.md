# 12｜企業原資型（治療費補助の設計・運用代行）：やる理由と、立てるタイミング

作成：2026年8月28日／【CFO】【CPO】主担当（VC・法務レビュー済み想定）
経緯：社長の問い「治療費ファイナンスは儲かりそうだが、10億円を考えたときにあえて外す理由はあるか」（2026-08-28）への回答から派生。**ローン本体はやらないが、お金に関わる収益線は別の形で立てられる**という結論に至ったため、独立した検討として記録する。

> 数字はすべて仮定。`11-root-pain-and-equity.md` §3の選択肢Cに対する**代案**として追加する。

---

## 1. なぜローンではなくこれなのか（要約）

ローン本体を外した理由は倫理ではなく**市場サイズと資本効率**だった。

- 患者の実質自己負担は年400〜600億円規模（2022年度の保険診療医療費896億円・実患者数37万3,575人から推計。自費部分は統計がなく**要確認**）。借入検討層を2割としても貸付実行額の市場全体は年80〜120億円
- **市場を100%取ってようやく金利収入10億円。その時点で200億円超の貸付残高＝調達が必要**。現実的なシェア10%なら年4,000万〜1億円で、10億の1割に届かない
- 加えて、2022年の保険適用が**Gaia型にとって一番おいしい層（初回〜3回目）を国が吸収**した。日本で自費に落ちるのは回数上限を使い切った層＝成功確率が下がっている層で、成果連動保険としては逆選択の塊になる
- レンディングの売上マルチプルはSaaS・サービスの1/3〜1/5。**G-CHALLENGEの「時価総額100億円」基準ではむしろ不利**

一方、Progynyの売上12.9億ドルの中身は fertility benefit services 8.3億ドル＋pharmacy benefit services 4.6億ドル——**個人に貸す事業ではなく、雇用主の予算を預かって給付を管理する事業**である。**個人に貸すのではなく、企業の原資を運ぶ側に回る。**

## 2. 提供価値の核——「企業が、誰が治療中かを知らずに補助を出せる」

これが唯一無二の価値提案であり、他の全部より重要なので先に書く。

**いま企業が治療費補助制度を作っても使われない最大の理由は、申請すると人事に知られるからである。** 職場に一切伝えていない人が47.1%いる状況で、「治療費の領収書を人事に出してください」という制度は、設計上ほぼ使えない。**制度が沈黙の均衡を壊せず、むしろ沈黙を可視化する装置になっている。**

ACOVIAが間に入ると、この構造が変わる。

| | 現状（企業が直接運用） | 企業原資型（ACOVIAが間に入る） |
|---|---|---|
| 申請先 | 人事部 | ACOVIA |
| 企業が知ること | **誰が・いつ・いくら** | 月次の**集計のみ**（人数・総額） |
| 領収書・診断書 | 人事が見る | ACOVIAのみが見る |
| 本人の心理的障壁 | 高い（開示が前提） | 低い（匿名で受け取れる） |

**これはD-018（支払者の利益と本人の選択が割れたら本人に付く）の実装そのものである。** 個人単位のレポートを出さないという約束が、給付管理では「匿名で補助を受け取れる」という具体的な機能になる。**倫理的な制約が、そのまま機能的な差別化になっている**——この構造は、事業として非常に強い。

## 3. サービスの中身

| 構成要素 | 内容 | 課金 |
|---|---|---|
| ①制度設計 | 就業規則・補助要項の作成、対象範囲（本人／配偶者／養子縁組等）、上限額の設計、両立支援等助成金（最大90万円）とくるみんプラスの取得支援 | 初年度 50〜100万円（一時金） |
| ②申請・給付の運用代行 | 従業員からの申請受付、対象可否の確認、領収書の検認、企業への請求と支払実行の手配、**企業へは集計のみ返す** | 年200万〜2,000万円（規模別・下記） |
| ③助成金の取りこぼし回収 | 自治体助成・高額療養費・医療費控除のナビゲーション（`11`選択肢A）。**企業の原資を使う前に、公的制度を先に使い切る** | ②に内包 |
| ④集計レポート | 利用人数・総額・年代分布（**個人が特定される粒度では一切出さない**）。制度の見直し提案 | ②に内包 |

**単価（仮定）**：1,000名規模で年200〜400万円／5,000名規模で年600〜900万円／1万名規模で年1,000〜2,000万円。既存の年間契約（相談＋研修、平均168万円）に**上乗せ**する形なので、**大企業のARPUが跳ねる**。

## 4. いつ立てるか——4つの前提が揃う時期から逆算する

この事業は「思いついたら始められる」類ではない。前提を先に置く。

| # | 前提 | 揃う時期 | 理由 |
|---|---|---|---|
| 前提1 | **年間契約が20社以上ある** | FY2029前半 | 新規で売る商品ではなく**既存顧客へのアップセル**として出すのが唯一現実的。母数がないと売り先がない |
| 前提2 | **助成ナビが実務として回っている** | FY2028末 | ③は②の前提。公的制度を使い切る知見がないまま企業の原資を運ぶと、企業に無駄払いをさせる |
| 前提3 | **資金の流れの法務整理が済んでいる** | **着手前に必須** | 企業から預り金を受けて患者・クリニックに払う形は、資金決済法の「為替取引」該当性の整理が要る。**収納代行スキームか、企業が直接支払い（ACOVIAは可否判定と指図のみ）か**。後者なら規制は軽い。**要確認事項の最上位** |
| 前提4 | **オペレーション人員がいる** | FY2029（シリーズA後） | 領収書検認・請求・支払指図は、相談や研修と全く別の業務。片手間ではできず、品質事故（誤支給・情報漏洩）は致命的 |

### 立てるタイミング（決定）

| 時期 | やること | 状態 |
|---|---|---|
| **FY2028 Q4** | 法務整理（前提3）に着手。**支払指図型（企業が直接支払い、ACOVIAは可否判定と指図のみ）を第一候補**として社労士・弁護士に確認 | 準備 |
| **FY2029 Q3** | 設計着手。**既存の年間契約先2社で無償パイロット**（制度設計のみ・運用代行なし） | パイロット |
| **FY2029 Q4** | パイロットの利用実績を検証。②の運用フローとオペレーション人員（1名）を確定 | 検証 |
| **FY2030 Q2** | **有償メニュー化。** 既存顧客へのアップセルとして提供開始。大企業・健保組合経由を優先 | 販売開始 |
| **FY2031** | 収益線として成立。大企業5社＋中堅25社を目標 | 収益線 |

**FY2029 Q3という時期は、「シリーズA調達直後で人が採れ、年間契約が40社を超え、助成ナビが1年動いた後」に一致する。** これより早いと前提が欠け、これより遅いと10億に間に合わない。

## 5. 10億円の構成への影響

| | 従来の見込み（`sim-v3`） | 企業原資型を加えた場合 |
|---|---|---|
| FY2030 | 2億4,000万円 | 2億6,000万円（＋2,000万・立ち上げ期） |
| **FY2031** | **8億2,000万円** | **9億4,000万円（＋1億2,000万）** |
| 10億到達 | 2032年後半 | **2032年前半**（前倒し） |

内訳（FY2031・仮定）：大企業5社×平均1,200万円＝6,000万円／中堅25社×平均250万円＝6,250万円。

> 【CFO】**ただし粗利率は下がる。** 相談・研修の粗利率62%に対し、給付管理は人手のかかる業務で40〜50%程度。全社粗利率は64%→60%前後に希釈される。**売上は増えるが利益率は下がる**ことを織り込んで判断すること。それでも支持する理由は、①大企業のARPUが跳ねて社数依存から抜けられる ②解約されにくい（制度に組み込まれると乗り換えコストが高い）③②の情報が④のレポートを厚くし、相談・研修の更新率を上げる、の3点。

## 6. リスクと歯止め

| リスク | 歯止め |
|---|---|
| **給付管理会社になり、相談・研修が付属品になる** | 給付管理の売上比率に**上限20%**を置く（研修の30%上限と同じ思想）。超えたら主語がずれているサイン |
| 誤支給・情報漏洩 | 医療情報を扱うため、**要配慮個人情報**としての管理体制を先に作る。保険（サイバー・賠償）加入。前提4の人員なしに始めない |
| 企業が「使った人リスト」を要求する | **断る**（D-018）。ここは交渉しない。断れる契約数になってから始めるべき理由でもある |
| 資金決済法・保険業法への抵触 | 前提3。**支払指図型を第一候補**とし、預り金を持たない設計を優先 |
| 原資が小さすぎて意味のない制度になる | 制度設計（①）の段階で、上限額の妥当性を助成金・高額療養費と合わせて試算する。**「年5万円の補助」のような形だけの制度は作らない** |

## 7. 判定

**やる。ただしFY2029 Q3から。** それ以前に前倒しする条件は1つだけ——**大企業または健保組合から先に求められた場合**（プル型の引き合いは、前提1〜2を飛ばす正当な理由になる。ただし前提3・4は飛ばせない）。

**社長への確認事項**
1. 給付管理の売上比率上限20%（§6）を置いてよいか
2. 前提3の法務整理（資金決済法の該当性）を、FY2028 Q4のタスクとして先に置いてよいか。**支払指図型（預り金を持たない）を第一候補とする方針でよいか**
3. 10億の構成を書き換える（`05-financial-plan.md`の収益線に追加する）ことを承認するか
