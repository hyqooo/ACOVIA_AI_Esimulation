# 実行シミュレーションv2｜共通ルール（審査員・メンターエージェント版）

作成：2026年8月22日／ACOVIA AI経営チーム
v1（3周版）は「経営チームの一人語り」だった。v2では**独立したエージェントを実際に立て、その出力に経営チームが従う**。結果は経営チームがscriptしない。

## v1との違い

| | v1 | v2 |
|---|---|---|
| メンター | なし | **月森賢一（架空・57歳・連続起業家/実務家教員）を独立エージェントとして起動**。月次〜隔月で実データを見せて指導を受け、従うか反論するかを都度決める |
| 審査 | 経営チームが結果を自作 | **審査員パネル（架空3名）を独立エージェントとして起動**。エントリー書類（ドシエ）を渡し、落選/ファイナリスト/KIBOW賞/大賞を判定させる。判定理由・講評も審査員が書く |
| ピボット | 想定せず | **視野に入れる**。メンター・審査員のフィードバック次第で事業モデル自体を転換する |
| 粒度 | 四半期サマリー | **月次。何を作り、いくらで売り、何件断られ、誰が何を決めたか**まで記録 |

## 登場エージェント（すべて架空の人物。実在の人物ではない）

- **メンター・月森賢一**：連続起業家（IPO1社・清算1社）→ヘルスケア2社社外取締役→実務家教員。単刀直入、数字で詰める。口癖「それは事実ですか、仮説ですか」「先週のあなたの10時間は何を売りましたか」
- **審査員パネル**：如月（委員長・VC歴20年・B2B SaaS中心）、榛名（ヘルスケア投資・元医師）、志摩（インパクト投資）。投資判断の目で合議。同年度の competing エントリー（AI SaaS・創薬支援等）との相対感も持つ

## 不変のルール（v1から継承）

- スタート地点は毎周2026年8月末。3名兼業（代表12h/週・副代表12h/週・山口さん6h/週）、自己資本ほぼなし、無償テスト開始直後
- 周回間で持ち越せるのは「学び（L番号）」のみ
- 初めての試みは悲観寄り、学習済みは中位の結果。奇跡の追い風禁止。既知の失敗パターン22個は地雷リスト
- 相手には相手の事情（クリニック稟議6〜12ヶ月、企業の年度予算、審査は年1回）
- 成功＝**審査員エージェントが大賞を授与**＋専業化ライン＋MVV整合。経営チームの自己判定は不可
- 数字はすべて仮定。実在の団体・個人の見解ではない

## 記録の形式

各周のファイルは月次で、以下を必ず含む：
1. **何をしたか**（作ったもの・売ったもの・価格・チャネル・件数）
2. **何が起きたか**（成約・失注・断られた理由の生の言葉）
3. **何を決めたか**（経営会議の判断。誰が何と言ったか）
4. **メンターとのやりとり**（指導の内容→従ったか、反論したか、その結果）
5. **審査**（ドシエの中身→審査員の判定と講評→チームの受け止め）
