## 1.【CEO】基本方針——「大賞をとれる企業」の定義から始める

G-CHALLENGE大賞の評価軸は、①経営者の志と経営メンバー、②市場規模・成長性、③実現可能性、④競争優位性、⑤収益性、⑥株主構成と株価の妥当性。求められる規模感は**年間売上10億円以上または時価総額100億円程度以上**のストーリーである。

したがって「大賞をとれる企業になる」とは、次の4つを同時に成立させることと定義する。

1. **10億円級の成長ストーリーが、願望ではなく構造で描けること**——不妊治療のピア傾聴単体では市場の天井が低いと審査で刺される（想定失敗パターン⑨）。Missionどおり「人生の難しい意思決定を支援する会社」として、不妊治療をビーチヘッドに、意思決定支援の型とAIプロダクトを他領域（がん治療・介護・出産・転職等）へ展開する**Decision OS路線**をストーリーの幹に置く
2. **社会的インパクトと財務リターンの両立を証明すること**——社長回答5のとおり、ACOVIAの本命は社会的インパクト（KIBOW賞の領域）にある。それをあえて大賞（財務リターン）水準で律するのが本シミュレーションの狙い。したがって**大賞＋KIBOW賞のダブル受賞を正式目標**とし、セオリーオブチェンジと10億円級ストーリーを同じ事実から両面で描く
3. **フェーズ相応のトラクションがあること**——審査は「事業フェーズに応じた内容・進捗か」を見る（説明会確認済み）。2028/2本選時点で、有償顧客・B2B契約・成果データ・プロトタイプという「初期段階として文句のない証拠」を揃える
4. **出資を受けられる会社であること**——ファイナリストは出資辞退不可。株式会社であること、経営陣が株式の大多数を保有し独立して意思決定できること、フルコミット1名（受賞後1年以内でも可）が要件。資本政策をこの前提で設計する

### 3つの原則

1. **証拠の階段は飛ばさない**——VC型に転換しても、90日検証（〜10/31）のGate①〜⑤判定は不変。トラクションのない壮大なストーリーは大賞では勝てない（審査員は投資判断の視点で見る）。現実の検証活動が、そのままG-CHALLENGEの「進捗」になる
2. **2026年度は挑戦、2027年度は勝負**——2026年度エントリーは、実績ほぼゼロでの挑戦。目的は(a)本気の事業計画書を一度完成させること、(b)書類選考フィードバック（落選でも必ず貰える）で審査観点を学ぶこと、(c)もし本選に進めばそれ自体が大きな前進。ただし**ファイナリストになれば出資辞退不可**のため、「練習」ではなく本気の応募として設計する
3. **Missionの主語は変えない**——VC型に転換しても、K'の4つの栓（相談件数のKPI化禁止・謝礼圧縮禁止・紹介料/掲載料禁止・相談者に直接触れるAIの封印）のうち、前三者は維持。ただし「相談者に触れるAI」は、社長回答6により**安全設計とセットでの段階解禁を確定方針**とする（10億ストーリーに非人力スケールが必須のため。解禁判断はPhase 2のGateで行い、専門家レビュー・免責設計・危機検知フローを条件とする）

## 2.【VC】【CFO】10億円級ストーリーの構造（すべて仮定）

### 市場の描き方（審査向けストーリー）

- **ビーチヘッド（不妊治療）**：体外受精は年間約50万周期・2022年保険適用で拡大、治療と仕事の両立に悩む就労女性は多数——数値は要確認。エントリー資料作成時に一次統計（ART登録データ・厚労省調査）で裏取りする
- **本丸（人生の難しい意思決定の支援市場)**：がん治療選択・介護方針・出産・離婚・転職・移住。個々の領域に相談産業はあるが、「情報・感情・価値観を整理して自分で決める」ことに最適化された横断プレイヤーは不在——ここが「なぜ今か・なぜ私たちか」の核
- **競争優位性**：①経験者ネットワークと傾聴の型（人的資産）、②構造化対話・Decision Noteの方法論（再現性資産)、③匿名化された意思決定プロセスデータ（データ資産）。無料AI相談との差別化は「人だから」ではなく「成果データと安全設計」で説明する

### 売上10億円の構成イメージ（5年後・2031年ごろの姿として提示する仮定）

| 収益源 | 単価×数量（仮定） | 売上（仮定） |
|---|---|---|
| 企業福利厚生（両立支援・意思決定支援） | 年100〜200万円 × 300〜500社 | 4〜7億円 |
| 医療機関B2B2C（不妊クリニック→他診療科へ） | 年100〜150万円 × 150〜250院 | 2〜3億円 |
| C2Cセッション＋プログラム | — | 0.5〜1億円 |
| Decision Guide/OS（SaaSライセンス） | — | 1〜2億円 |
| 隣接領域（がん・介護等）パイロット | — | 0.5〜1億円 |

- 2029年時点の目標は売上1〜2億円（後述Y3）。「10億は2031年、そのための構造は2028年までに証明」という時間軸で審査に説明する
- 粗利率目標60〜65%（AI支援による人的コスト逓減が前提。Ver3感度分析のとおりセッション単価のみでは不可能）

### 資本政策（仮定）

- Phase 1で**株式会社**を設立（G-CHALLENGEは非営利法人不可・法人登記＝起業の定義。前シリーズの合同会社方針から変更）
- 創業株主は3名。経営陣が大多数を保有し独立性を維持（応募要件）
- 調達ロードマップ：創業融資300〜500万円（公庫）→ G-CHALLENGE出資500〜1,000万円（受賞時・転換株式orマッチング）→ シード5,000万〜1億円（2028年・大賞受賞をシグナルに）→ シリーズA（2029〜30年・隣接領域展開の資金）
- 転換株式条件（30%割引・Cap5億円・18ヶ月で2億円転換）は交渉余地あり（説明会確認済み）。18ヶ月以内に適格増資（第三者1,000万円以上）を起こせるかがシード調達のデッドラインになる点に注意

### 専業化ライン（与件・前シリーズの条件式を準用）

- 条件式（仮定）：直近3ヶ月平均の月商が「本人報酬50万円＋変動費＋固定費按分」を賄い、翌6ヶ月の受注見込みが立つこと。**またはシード調達完了後に役員報酬として設定**（VC型ではこちらが現実的）
- 順序：副代表（倉元さん・800万ライン）が先行し、代表（菅原さん・1,000万ライン）は後追い可
- ただし【法務】注記：G-CHALLENGE要件は「起業時に最低1名がフルタイムコミット」。受賞して法人設立する場合、設立時点で誰か1名の専業化が必要になる。シード調達前なら報酬水準は専業化ラインに達しない可能性が高く、**「専業化ライン到達→専業化」の順序が「専業化→報酬が後から追いつく」に逆転するリスク**がある。これは受賞決定時（2027/2または2028/2）の最重要論点として先置きする

## 4.【CMO】需要と審査、2つの聴衆に同じ事実を語る

- **顧客への言葉**は変えない：「不妊治療 つらい」「結果が悪かった日」「ただ聞いてほしい」。急性感情トリガーのビーチヘッド維持。最大の競合は「何もしないこと」
- **審査員への言葉**は翻訳する：同じ事実を「意思決定支援の未開拓市場」「経験者ネットワーク×構造化対話×データの三層防壁」「保険適用拡大・両立支援義務化という追い風（要一次情報裏取り）」として提示
- 落とし穴：審査向けストーリーが先行して顧客の現実から乖離すること（想定失敗パターン11）。エントリー資料に書く数字は、実際に観測した数字と仮説の数字を必ず区別して記載する（審査資料にも「検証中」と正直に書く方が、投資家視点では信頼される）

## 5.【COO】【CHRO】組織・供給の方針

- 役割分担（仮定）：代表＝聞き手品質・育成・対外の顔（本選プレゼンター）／副代表＝事業開発・財務・資本政策・エントリー実務／山口さん＝プロダクト（Decision Guide）・ツール・データ基盤。**「山口さんにしかできない状態」を作らない**原則は維持しつつ、2年間の限られた稼働はプロトタイプ開発に集中
- サポーター供給：需要証明前に集めすぎない（Phase 1末で認定3名、Phase 2末で8〜10名・仮定）。メンバー→サポーター循環モデルを本命に
- 安全運用：緊急連絡先リスト記入完了はPhase 0の必須タスク（現実の最優先ギャップ）。安全即応の一次責任者は代表以外に置く設計を検証
- 受賞後の採用（仮定）：2028年にエンジニア1名・オペレーション1名。出資・調達資金の主使途

## 6.【法務・倫理】守る線と新たな論点

- 医療助言の境界・録音と匿名化・守秘義務・レッドフラグ対応は決定済みルールを維持
- **新論点①**：相談者に触れるAIの段階解禁（Phase 2 Gate）。解禁時は専門家レビュー・免責設計・危機検知フローを条件とする
- **新論点②**：株式会社化に伴う定款・株主間契約。経営陣の独立性（応募要件）を守る設計
- **新論点③**：本選はオンライン配信され、受賞プランは概要が公開される。個人情報・営業秘密の露出範囲を事前に設計
- **新論点④**：出資意思確認書への署名は、3名全員の合意と（可能なら）専門家への相談を経てから行う

## 7.【VC】反対意見——この計画の弱点を先に言う

1. **市場の天井問題が最大の急所**。不妊治療ピア傾聴は「善い事業」だが、審査員が見るのは10億の実現可能性。隣接領域展開はまだ紙の上のストーリーであり、2028/2時点でも「不妊治療で証明された型が他領域でも動く」証拠は薄い。→ 対策：Phase 3を待たずKIBOW賞併願で社会的インパクト軸も取りに行く。ダブル受賞は狙って悪いものではない
2. **2026年度応募は現実の決定（今年はパス）と依然矛盾**している。社長回答7により8/25定例には載せない方針が確定したため、現実に応募するには社長が9月中旬までに別ルートで意思決定する必要がある。それがなければ2026年度応募はシミュレーション内にしか存在しない——この計画を読む人はその前提を忘れないこと
3. **出資辞退不可**は重い。2026年度に「思いがけず」ファイナリストになった場合、VC型転換が18ヶ月の適格増資タイマー付きで即座に始まる。準備不足での受賞は、むしろ資本政策の自由度を奪う——書類提出前に「受かっても本当に良いのか」を3名で最終確認せよ
4. **専業化の順序逆転リスク**（§2末尾）。フルコミット要件と兼業前提の与件は、受賞の瞬間に衝突する。誰が最初に飛ぶのか、収入の谷をどう埋めるのかは、受賞前に決めておく問題
5. **相談者に触れるAIの封印解除**はMission・安全・差別化のすべてに関わる不可逆な一手。Gateを置いたとはいえ、10億ストーリーの圧力で判断が歪む懸念は残る
6. それでも支持する理由：撤退・転換条件（R-G0〜R-G2）が全Phaseに先置きされ、「トラクションなき応募」「粉飾したストーリー」を構造的に塞いでいる。挑戦→学習→本命の二段構えは、フィードバックが必ず貰えるこのコンテストの仕様と噛み合っている
