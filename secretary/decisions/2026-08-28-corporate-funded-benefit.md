# [D-021] 治療費ファイナンス本体はやらない／企業原資型（給付管理）をFY2029 Q3から立てる

| 項目 | 内容 |
|---|---|
| 決定日 | 2026-08-28 |
| 関連する仮説 | 該当なし（収益構造） |
| ステータス | 決定（ローン本体）／**方針決定・実行はFY2029 Q3**（企業原資型） |
| 決定タイプ | 可逆 |
| 決めた人 | 社長（Hiroki）の問い「治療費ファイナンスをあえて外す理由はあるか」を受け、AI経営チームが分析・提案 |
| 関連する成果物 | `growth-v3/12-corporate-funded-benefit.md`／`growth-v3/11-root-pain-and-equity.md` §3 |

## 決めたこと

1. **治療費ファイナンス本体（Gaia型の成果連動保険・個人向けローン）はやらない**
2. 代わりに**企業原資型（治療費補助の設計・運用代行）を収益線として立てる。着手はFY2029 Q3**

### 立てるタイミング

| 時期 | やること |
|---|---|
| FY2028 Q4 | 法務整理に着手（資金決済法の為替取引該当性）。**支払指図型＝預り金を持たない設計を第一候補** |
| **FY2029 Q3** | 設計着手。既存の年間契約先2社で無償パイロット（制度設計のみ） |
| FY2029 Q4 | 運用フローとオペレーション人員1名を確定 |
| FY2030 Q2 | 有償メニュー化。大企業・健保組合経由を優先 |
| FY2031 | 収益線として成立（大企業5社＋中堅25社。約1億2,000万円） |

## 決めた理由

**ローン本体を外したのは倫理ではなく市場サイズと資本効率。**

- 患者の実質自己負担は年400〜600億円規模（2022年度の保険診療医療費896億円・実患者数37万3,575人から推計。自費部分は統計がなく要確認）。借入検討層を2割としても貸付実行額の市場全体は年80〜120億円
- **市場を100%取ってようやく金利収入10億円。その時点で200億円超のバランスシートが必要**。現実的なシェア10%なら年4,000万〜1億円で、10億の1割に届かない
- 2022年の保険適用が**Gaia型にとって最も引き受けたい層（初回〜3回目）を国が吸収済み**。日本で自費に落ちるのは回数上限を使い切った層＝逆選択の塊
- レンディングの売上マルチプルはSaaS・サービスの1/3〜1/5。**G-CHALLENGEの「時価総額100億円」基準ではむしろ不利**
- 人事部が「従業員にローンを組ませる会社」と福利厚生契約を結ぶか——**6億円の主柱を毀損して1億円を取る**構造になる

**企業原資型を選んだのは、Progynyの売上12.9億ドルの中身が「雇用主の予算を預かって給付を管理する事業」だから**（fertility benefit services 8.3億ドル＋pharmacy benefit services 4.6億ドル）。個人に貸すのではなく、企業の原資を運ぶ側に回る。

## わかったこと（最も重要な発見）

**企業が「誰が治療中か」を知らずに補助を出せる**——これが唯一無二の提供価値。

いま企業が治療費補助を作っても使われない最大の理由は、申請すると人事に知られるから。職場に一切伝えていない人が47.1%いる状況で「領収書を人事に出してください」という制度は、設計上ほぼ使えない。ACOVIAが間に入ると、企業には集計のみが返り、本人は匿名で受け取れる。

**D-018（本人に付く）という倫理的な制約が、そのまま機能的な差別化になっている。**

## 影響

- FY2031売上：8億2,000万円 → **9億4,000万円**。10億到達が2032年後半 → **2032年前半**に前倒し
- **ただし粗利率は下がる**（給付管理は40〜50%。全社64%→60%前後に希釈）
- 売上比率の上限20%を置く（研修の30%上限と同じ思想）

## 再検討条件

- **前倒しの条件**：大企業または健保組合から先に求められた場合（プル型の引き合いは前提1〜2を飛ばす正当な理由になる。ただし法務整理と人員は飛ばせない）
- **中止の条件**：FY2029 Q4のパイロット2社で、制度設計まで進んで運用に至らない／給付管理の売上比率が20%を超える
- **ローン本体の再検討条件**：①保険適用の回数上限が撤廃or大幅緩和され自費の帯が構造的に変わる ②事業と資本を分離した別法人を持てる規模になる ③大手金融機関から商品監修＋ライセンスの提案が来る（リスクを負わず中立性への影響が小さい形）
