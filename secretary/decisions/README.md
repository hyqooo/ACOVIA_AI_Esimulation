# decisions/｜意思決定ログ

## 目的
1件＝1意思決定。実在のACOVIAのNotionにある意思決定データベースの構成（Name／仮説／ステータス／決定タイプ／決定日／わかったこと）を模している。

議事録（`../minutes/`）が**過程**の記録であるのに対し、ここは**結果**の記録。あとから「何が決まっていて、何が決まっていないか」を1件単位で引けるようにする。

## 運用ルール
- 1決定1ファイル：`YYYY-MM-DD-スラッグ.md`
- **決めなかったこともログに残す。** 「決めない」と決めたのなら、それは意思決定である
- 決定を覆した場合は、元のファイルを消さず、新しいファイルを作って「〜を覆す」と明記する
- **再検討条件を必ず書く。** 何が起きたらこの決定を見直すのか。これがないと、決定は思考停止になる

## 書式

```
# [D-001] 決定の名前

| 項目 | 内容 |
|---|---|
| 決定日 | 2026-07-31 |
| 関連する仮説 | 意思決定伴走型 ／ ピアサポート型 ／ 両方 ／ 該当なし |
| ステータス | 決定 ／ 保留 ／ 覆した |
| 決定タイプ | 不可逆 ／ 可逆 |
| 決めた人 | 社長（Hiroki）／ CEO ／ 合議 |
| 関連する議事録 | ../minutes/YYYY-MM-DD-〇〇.md |

## 決めたこと

## 決めた理由

## 検討したが採らなかった選択肢

## 再検討条件
（何が観測されたら、この決定を見直すか）

## わかったこと
（この決定の過程で新しく分かったこと。なければ「なし」）
```

## 注意
「決定タイプ：不可逆／可逆」は、判断のスピードを変えるために書く。可逆な決定を慎重に議論しすぎることと、不可逆な決定を軽く決めることの両方を防ぐ。
