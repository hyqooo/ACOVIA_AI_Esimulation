# [D-003] 制約をMVVだけにしたシナリオ（E〜H）を4本追加する

| 項目 | 内容 |
|---|---|
| 決定日 | 2026-07-31 |
| 関連する仮説 | 両方（ただしE〜Hはどちらの仮説からも離れる） |
| ステータス | 完了 |
| 決定タイプ | 可逆（シミュレーションのため） |

## 決めたこと

A〜Dが「ACOVIAがすでに検討している選択肢の延長線上」にあったのに対し、**制約をMVVだけにした場合**の4本を追加した。会社の憲法の「やらないと決めていること」リストは、すべて使ってよいカードとして扱った。

| | 破った「やらないこと」 | 5年後 | 判定 |
|---|---|---|---|
| E｜恩送り | 大規模な相談員募集 | 年商6.8億円、サポーター720名 | 成功（労務論点は5年間未決） |
| F｜ドメインを捨てる | 他領域展開・大型調達 | 年商12億円、不妊治療は3% | 割れた |
| G｜規格になる | 「会社を成長させる」前提そのもの | 年商2.4億円、社員10名、利用者82万人 | 成功 |
| H｜物語に負ける | **なし（それが問題）** | 年商1,900万円（ピークの28%） | 失敗 |

## 決めた理由

「面白さ・クレイジーさ・スタートアップならでは感」という要望と、「MVVさえ変わらなければどうなってもいい」という制約緩和を、そのまま設計条件として使った。A〜Dは既存の思考の延長にあり、驚きが出にくい構造だった。

## 検討したが採らなかったシナリオ

- **国の制度に入り込む**（不妊治療の保険適用の枠に意思決定支援を組み込む）— 成否が政治に依存しすぎ、経営シミュレーションとして学べることが少ない
- **経験者マッチング市場**（あらゆる難しい選択に経験者をマッチ）— FとEの組み合わせでほぼ説明できる
- **AIサポーター**（匿名化ログで専用モデル）— シナリオAで既に、人間チェックを間引いてインシデントに至る道を描いている

## わかったこと

1. **A〜Dの結論を1つ訂正する必要がある。** 「即時性と経済性の両立は、AIチームが完全に経営しても構造的に解けない」→ 正しくは **「供給を自社で抱える限り解けない」**。シナリオE（恩送り）で解けた。待機コストは、待機する人が多ければ一人あたり小さくなる
2. **「会社の成長」と「Missionの達成」は切り離せる**（G）。売上とインパクトが競合しない構造にすると、両方を指標として見続けられる。AとDは、競合したから片方を見なくなった
3. **倫理はコストとして現れ、遡って保険になる**（F対H）。まったく同じ構造の炎上で、2年前から逆方向の数字を契約条項として公開していたFは乗り切り、集計はしていたが公開していなかったHは3ヵ月で瓦解した
4. **MVVは方向を決めるが、形は決めない。** E〜Hはすべて MVV を一度も変えていない。それでも5年後は年商1,900万円から12億円まで散った。「この形でありたい」があるなら、MVVとは別に明示的に書く必要がある

## 新しく登録した失敗パターン

**パターン13：自分たちが何者かを、外の人の言葉で説明できない**（シナリオHで顕在化）

会社の憲法の12パターンはすべて**事業の中身**の失敗である。Hは中身が最後まで正しかった。顧客成果も更新率もUnit Economicsもシナリオ相当。壊れたのは、中身を外から説明できなかったからである。

## 現実のACOVIAへの問い（数字ではなく問いだけを持ち帰る）

1. **E**：セッション後に「私も誰かの役に立ちたい」と言う人が出たら、それを**供給として見るか**。回復の兆しとしてだけ見るか
2. **F**：不妊治療以外の領域から「そのフォーマット、うちで使えませんか」と言われたら、**受けるか**
3. **G**：Decision Note を無料で公開してほしいと言われたら、**断るか**
4. **H**：「やめる決断を後押ししてもらえた」という感謝に対して、**逆方向の数字を平時から公開できるか**
