## うまみと煩雑さ

<b>うまみ</b>

| 項目 | 中身 |
|---|---|
| 単価と継続性 | 1件300〜600万円/年。複数年にわたり同じ事業者が受託し続けやすい |
| 公的な信用 | 自治体の受託実績は、企業営業でも他自治体営業でも効く。新設法人が最も欲しい信用 |
| ミッション適合 | 相談窓口は全都道府県にあるが、地方は週1回2時間〜月1回開設の例が多い。相談実績も大阪府延べ3,498件に対し鳥取県は5年間で電話326件と大差。**地域格差の是正はKIBOWストーリーに直結する** |
| 供給側の受け皿 | 認定ピアサポーターの稼働枠を実際に作れる。需要と供給の空白を同時に埋めるという事業の骨格そのもの |
| 予防・啓蒙の解禁で急上昇 | D-019により、自治体が予算を持っている**プレコンセプションケア・若年層向け啓発**が入り口として使えるようになった。相談窓口の受託より契約規模が小さく、参入が軽い |

<b>煩雑さ</b>

| 項目 | 中身 |
|---|---|
| **実績要件** | プロポーザル・入札の参加要件に「過去3〜5年の同種業務実績」が入ることが多い。**新設法人はここで機械的に弾かれる。これが最大の壁** |
| 年度サイクル | 前年秋〜冬に仕様策定、1〜3月に公募、4月開始。**思い立ってから最短で1年後** |
| 単年度契約 | 翌年度の継続保証がない。人を張ってから切られる риск |
| 支払サイト | 年度末一括・前払い不可が多い。**兼業3名・自己資本ほぼなしの現状ではキャッシュフローが持たない** |
| 提案工数 | 仕様書読解・提案書・見積・体制図。1件あたり数十時間。3名の稼働（週25〜32時間）を丸ごと食う |
| その他 | 情報セキュリティ要件、詳細な報告書、議会・住民対応の政治性 |

## 交点をどこに置いたか

**壁は「実績要件」と「キャッシュフロー」の2つで、どちらも時間でしか解けない。** 一方でうまみの大半（信用・稼働枠・インパクト）は、入札を取らなくても小規模な随意契約や再委託で手に入る。したがって、**入札に正面から挑むのを後ろに置き、実績づくりを先に置く**。

| 時期 | やること | やらないこと |
|---|---|---|
| 〜2028年度 | **何もしない**（企業向けに集中）。ただし公募情報の定点観測だけは週次情報収集に入れる | 入札・プロポーザルへの応募 |
| 2028〜2029年度 | **小規模の随意契約を1〜2件取りに行く**。狙いは予防・啓蒙側（若年層向けライフプラン講座、プレコンセプションケア啓発。50〜200万円規模）。既存受託事業者（助産師会・NPO・企業）からの**再委託・共催**も同じ枠で狙う | 相談窓口の運営受託そのもの |
| 2029年度〜 | 実績2件を根拠に、**相談事業のプロポーザルへ単独で応募**する | 複数自治体への同時応募（工数が持たない。年2件まで） |

## 決めた理由

- 実績要件は「経験がないと取れない、取れないと経験ができない」という循環である。**これを断つ唯一の現実的な方法が、小規模・随意契約レベルの啓発事業から入ること**。D-019で予防・啓蒙が解禁されたことで、この入り口が使えるようになった
- 支払サイトの問題は、法人化・調達後（2028年以降）なら耐えられる。現状の自己資本では耐えられない
- 提案工数は、営業担当を採用した後（2028年末以降）でなければ捻出できない。3名兼業の稼働を自治体提案に使うと、企業営業が止まる

## 再検討条件

- 自治体側から声がかかった場合（公募ではなく相談ベース）→ 時期を待たず個別に判断する。**この決定は「攻めない」であって「断る」ではない**
- 企業向けB2B2Eが2028年末までに軌道に乗らない → 自治体を代替チャネルとして前倒しで検討する
- 2029年度に応募して2年連続で落選 → 自治体チャネルを事業計画から外す
