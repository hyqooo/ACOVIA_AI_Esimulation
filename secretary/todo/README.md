# todo/｜タスク台帳

## 目的
会社のタスクを1か所に集める。チャットのセッションが終わっても、ここを見れば「今、何が止まっているか」が分かる状態を保つ。

## 運用ルール
- 現在進行中のタスクは `open-tasks.md` にまとめる
- 完了したタスクは削除せず、`done/YYYY-MM.md` に移す（記録を消さない）
- 各タスクには必ず**担当部署**と**ブロッカーかどうか**を書く
- 「有償MVPの開始をブロックしているか」は最重要の属性。ブロッカーは一覧の先頭に置く

## タスクの書式

```
### [T-001] タスク名
- 担当：coo-chro/
- 種別：ブロッカー ／ 通常 ／ 検討
- 期限：2026-08-03（90日Gate開始日）
- 状態：未着手 ／ 進行中 ／ 完了 ／ 保留
- 内容：（1〜3行）
- 完了の定義：（何が存在すれば完了か。「検討する」で終わらせない）
```

## 注意
「完了の定義」を必ず書くこと。ACOVIAの失敗パターン12は「内部準備の完成度と、顧客価値の証明の混同」である。準備タスクが増え続けて、顧客に会う日が来ない状態を、この台帳で検知する。
