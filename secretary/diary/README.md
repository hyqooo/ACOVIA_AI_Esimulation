# diary/｜日々の記録

## 目的
「会社の記憶」の本体。チャットのセッションは終わるが、ここに書いたものは残る。

議事録（`../minutes/`）が会議の記録なのに対し、diary は**会議になっていない気づき・観測・変化**を残す場所。

## 運用ルール
- 1日1ファイル：`YYYY-MM-DD.md`
- その日に何かが動いたときだけ書く。毎日書かなくてよい
- **書くべきもの**：顧客から聞いた言葉（そのまま）、想定と違ったこと、前提が変わったこと、判断を保留したこと
- **書かなくてよいもの**：作業ログ、資料を作ったという報告
- 推測と観測を混ぜない。推測には「（推測）」と付ける

## 書式

```
# YYYY-MM-DD

## 観測
（実際に起きたこと・聞いた言葉。解釈を入れずに書く）

## 前提が変わったこと
（会社の憲法や、これまでの仮説と食い違った点。なければ「なし」）

## 気になっていること
（まだ論点になっていないが、引っかかっていること）
```

## 注意
顧客の言葉は、**社内用語に翻訳せずに残すこと**。「メンバーが意思決定の明確化を得た」ではなく、その人が実際に言った言葉をそのまま書く。翻訳した瞬間に、仮説が事実に見えてしまう。
