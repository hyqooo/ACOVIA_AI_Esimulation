# 議題3の材料｜G2（本命条件）に届く入口は、どこにあるか

# 0. 先に、1つ整理させてください

**G2 と G3 では、必要な経路の性質が違います。1つの経路で両方を満たす必要はありません。**

| | 条件 | 経路に何を求めているか |
|---|---|---|
| **G2｜本命条件** | 初対面 × **急性期** × 知人枠でない | **急性期の人に届くこと。** 反復可能かは問われていない |
| **G3｜有償E3** | 入金1件 ＋ **経路が個別依頼の外** | **個別依頼の外から来ること。** 急性期かは問われていない |

**これに気づくと、議題が軽くなります。**「急性期に届き、かつ反復可能で、かつ有償が発生する経路」を1つ探す必要はありません。**2つ別々でよいのです。**

# 1. 入口の型は、5つあります

**具体的なコミュニティ名は挙げていません。** 実在するか、規約が勧誘を許しているかを、**こちらでは確認できないためです。** 型と、確かめるべきことだけ書きます。

## 型1｜当事者が集まっている場所に、こちらから出向く

| | |
|---|---|
| **届き方** | **急性期の人が「いま」いる可能性が高い。** G2に直接効きます |
| **問題** | **多くのコミュニティは、勧誘・宣伝を規約で禁止しています。** 破ると、アカウント停止だけでなく**信用の毀損**につながります |
| **確かめること** | ① 規約で告知が許されているか ② 運営者に許可を取れるか ③ 「宣伝」ではなく「無償の場の提供」として受け入れられるか |
| **着手までの時間** | **短い**（規約の確認と、運営者への連絡） |

> **`legal-impact/` の注記**：**ここは慎重にしてください。** 不妊治療の当事者コミュニティは、**傷つきやすい人が安心のために集まっている場所**です。そこに「サービスの案内」を持ち込むことは、**たとえ無償でも、場を壊す形になりえます。**
> **運営者に先に話を通すこと。** それができないなら、この型は使わないほうがよいです。

## 型2｜治療の接点に置く（クリニック・薬局）

| | |
|---|---|
| **届き方** | **結果を聞いた直後の人に、その場で届く。急性期にいちばん近い入口です** |
| **問題** | **時間がかかります。** 医療機関との連携は、営業・信頼・書類が要ります |
| **確かめること** | 3人の誰かに、**話を持ち込めるクリニックの接点があるか** |
| **着手までの時間** | **長い。90日Gateの残りでは、まず間に合いません** |

> **これは90日Gateの外の話として置くべきです。** ただし**いちばん筋がよい入口**なので、**「いつか」ではなく「いつから始めるか」を決めておく価値はあります。**

## 型3｜検索で見つけてもらう（LPの検索登録）

| | |
|---|---|
| **届き方** | 「不妊治療 つらい」等で検索する人＝**まさに急性期**。G2に効きます |
| **問題** | **9/7で「有償化まで保留」と決めています。** かつSEOは数ヶ月かかります |
| **確かめること** | ① 保留の決定を覆すか ② 広告なら即効性はあるが、**費用が出せるか** |
| **着手までの時間** | SEOは**数ヶ月**。広告は**すぐ**（ただし費用） |

## 型4｜すでにいるメンバーからの紹介

| | |
|---|---|
| **届き方** | **すでに3人います。** その人たちが「いまつらい友人」を知っている可能性があります |
| **問題** | **メンバーに負担をかけます。**「誰か紹介して」は、相手の善意に頼む形です |
| **確かめること** | ① 頼んでよい関係か ② 頼み方（「もしいたら」の温度で言えるか） |
| **着手までの時間** | **いちばん短い。今日からできます** |

> **G2には効く可能性があります。G3には効きません。** メンバーの紹介は「個別依頼の外」ではありますが、**反復可能な経路ではありません**（3人しかいません）。

## 型5｜土日・夜に絞って、いまの導線のまま待つ

| | |
|---|---|
| **届き方** | **入口は増えません。** ただし競合（ピアサポート協会）は土日にサポーターがいません |
| **問題** | **そもそも来る人がいない状態は、変わりません** |
| **着手までの時間** | すぐ（費用ゼロ） |

> **これは入口ではなく「差別化」です。** 入口が別にあって初めて効きます。**単独では G2 は取れません。**

# 2. 90日Gateの残りで着手できるのは、2つだけです

| 型 | 残り期間で着手できるか |
|---|---|
| **型4｜メンバーからの紹介** | **できる。今日から** |
| **型1｜当事者コミュニティ** | **できる。ただし規約と運営者の確認が先** |
| 型3｜広告 | できる（費用が出せるなら） |
| 型3｜SEO | **間に合わない**（数ヶ月） |
| 型2｜クリニック | **間に合わない**（ただし筋はいちばんよい） |
| 型5｜土日・夜 | 入口ではないので、単独では効かない |

---

# 3. そのうえで、確かめていない前提が1つあります

> **急性期の人は、そもそもオンラインで、見知らぬサービスに申し込むでしょうか。**

期待より悪い結果を聞いた**当日〜翌日**の人が——

投稿を見る → LPを開く → 予約フォームを埋める → **日程の連絡を待つ** → 話す

**この一連の行動を、その状態の人が本当にするのか。** ここは**一度も確かめていません。**

| もし「する」なら | もし「しない」なら |
|---|---|
| **入口を増やせば、G2は取れます** | **入口を増やしても、G2は取れません。**「急性期に届ける」という設計そのものを考え直すことになります |

**いまは、どちらなのかも分かりません。**

> **`ceo-cpo/` の注記**：**議題4（当日・翌日枠を週1つ出すか）は、まさにこれを切り分ける仕掛けです。**
> **枠を出して埋まらなければ、「入口がなかった」のではなく「その行動をしない」側の証拠になります。**
> **議題3と議題4は、セットで考えてください。** 入口だけ増やしても、日程調整を挟む導線のままなら、**来るのは急性期を過ぎた人です**（9/6がそうでした）。

# 4. 決められる形にした選択肢

**議題3の A/B/C に、中身を入れました。**

| | 案 | 具体的に何をするか | いつから |
|---|---|---|---|
| **A** | **グロービス界隈だけで進め、G2は格下げ** | 投稿は G1（供給の練習相手）用と割り切る。**10/5にG2は判定しない** | すぐ |
| **B-1** | **＋ 型4（メンバーからの紹介）** | 3人のメンバーに「もしいたら」の温度で声をかける | **今日から** |
| **B-2** | **＋ 型1（当事者コミュニティ）** | **まず規約を読み、運営者に連絡する。** 許可が出てから告知 | 確認しだい |
| **C** | **G2の条件から「急性期」を外す** | 初対面 × 知人枠でない、の2条件にする | すぐ |

> **C案の危険（再掲）**：**「本命条件を試した」と言えなくなります。** 進行設計§8 が自分で書いている状態——「**初対面×急性期のメンバーでは一度も試していない**」——が、そのまま続きます。

**B-1 と B-2 は同時に選べます。** また **A と B は排他ではありません**（グロービス界隈をG1用に使いながら、G2用に別の入口を足せます）。

# 5. その場で確かめてほしいこと

> **① 3人のメンバーに「もしいたら紹介して」と言える関係ですか。**
> 言えるなら、**型4は今日から動きます。** 言えないなら、その理由が「関係」なのか「頼むこと自体への抵抗」なのかで、次が変わります。

> **② 型2（クリニック）に、誰か接点を持っていますか。**
> **90日Gateには間に合いませんが、「いつから始めるか」だけ決めておく価値があります。** いちばん筋のよい入口です。
