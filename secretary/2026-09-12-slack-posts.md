# Slack投稿用｜9/16の定例が飛んだあとの、非同期での決め方

作成：【秘書】／2026-09-12
用途：**Slackにそのままコピペして使う。** 上から順に、1本ずつ投げる
書式：**Slack記法**（`*太字*` はアスタリスク1つ）。表は使わず、箇条書きだけで書いています

> **使い方**
> - **投稿0を最初に投げてください。** これにOKが出れば、残りは全部Slackで回せます
> - **1本ずつ投げて、スレッドで返してもらう形**を想定しています。全部同時に投げると混ざります
> - 急ぐ順：**投稿0 → 投稿1（アンケート）→ 投稿2（保存期間・期限9/20）→ 投稿3（日程）→ 投稿4（経路）→ 投稿5（発話比率）→ 投稿6（順番）**

## 投稿0｜まず、進め方だけ決めさせてください

```
【まず、進め方だけ決めさせてください】

今週の定例が飛んだので、このまま行くと次に話せるのは9/23です。
90日Gateの残りは *49日* です。

■ 気づいたこと

いま残っているタスクを数え直したら、こうでした。

・*会議を待っていないもの：7件*
　ガイドのレビュー／アンケートのフォーム復旧／実施記録DBの記入／
　実施ガイドの公開設定／テストページの削除／送付物の確認／認証情報の失効
　→ 全部足しても *2時間かかりません* 。どれも1人でできます。

・*本当に会議が要るもの：2件*
　日程のリスケと、経路の方針だけ

そして、いちばん効く数字がこれです。

・実施件数：*5週で3件*
・同じ期間の会議：*5回前後*

→ *実施が増えないのは、会議が足りないからではありません。*
　 メンバーが集まっていないからです。

■ ただし、会議が律速に「なっている」構造はあります

9/7で「有償化はマイルストーンを決めてから、全員で考える」と決めました。
これ自体は自然な決め方です。
ただ結果として、*「マイルストーンが決まるまで動けない」構造* ができています。

例：グロービス界隈に投稿する文面を書くのに、会議は要りません。
1人が下書きしてSlackで2人がOKすれば済みます。

■ 提案

*「Slackで決めてよいこと」を、先に決めませんか。*

▼ Slackで決めてよいと思うもの
・投稿の文面（1人が下書き → Slackで2人がOK）
・ロープレの日程調整
・録音の保存期間（期限9/20。投稿2で投げます）
・実務作業（DB記入・フォーム復旧・公開設定など）

▼ 会議が要ると思うもの
・90日Gateの日程をどうするか
・経路の方針（どこで募集するか）
・有償化の可否
・価格

→ *上のリストでよければ「OK」とだけ返してください。*
　 直したいところがあれば、そこだけ言ってください。

これが決まったら、残りの論点を1本ずつSlackに投げます。
全部で6本、今日中に投げ切ります。
```

## 投稿1｜アンケートに2問足させてください（いちばん急ぎ）

```
【アンケートに2問足させてください】※いちばん急ぎます

■ なぜ急ぐか

*足さないまま実施した回は、二度と取り返せません。*
実施は5週で3件のペースなので、1件の重みが大きいです。

T-034（フォーム連携の復旧）で、どのみちフォームを触ります。
*そのついでに入ります。*

■ 足したい2問

▼ 1問目：話したあとに、何か起きたか

「話したあと、誰かに話した／何かをしたことはありますか」
（自由記述・任意）

→ 満足は「良かった」で終わりますが、
　 *そのあと本人が何をしたかは、行動の記録になります。*
　「夫に話してみた」「先生に聞いてみようと思った」——
　 これが出るかどうかが、傾聴が副次価値を生むかどうかの最初の観測です。

▼ 2問目：無料のAIでは足りないのか

「同じような気持ちのとき、AIやSNSに書いたことはありますか」
（ある／ない）

「ある」と答えた方へ：
「それでは足りなかったのは、どんなところでしたか」
（自由記述・任意）

→ *この事業がいちばん問われる質問です。*
　 無料のAIが「つらかったですね」と返す時代に、なぜ人でなければならないのか。
　 逆に「AIで足りた」が続くなら、それも早く知るべきことです。

■ 合格ラインの数字は、今は置きません

いま n=3、うち本命傾聴は1件です。
この分母で「50%以上」と決めても、*1件の有無で結論が反転します。*
→ 今日は「集計を始めること」だけ決めさせてください。

■ ついでに

*ニックネーム欄も足しませんか。*
9/7に「誰の回答か分からない」が実際に起きました
（価格の「2,000〜3,000円」の回答者が、いまも特定できていません）。

→ *「2問＋ニックネーム欄を足す」でOKなら、そう返してください。*
　 文面を直したいところがあれば、そこだけ教えてください。
```

## 投稿2｜録音の保存期間を決めさせてください（期限9/20）

```
【録音の保存期間を決めさせてください】※期限9/20

■ 状況

プライバシーポリシー（9/1制定）で、4つの要件のうち3つは確定済みです。
・保存場所：Google ドライブのアクセス制限フォルダ ✅
・閲覧範囲：管理者・対応したサポーター・今後対応する予定のサポーター ✅
・削除請求：いつでも申し出可。速やかに削除 ✅
・*保存期間：未定* ← ここだけ残っています

そしてポリシーには、こう書いてあります。
「現時点では定めておらず、*決定次第お知らせし* 、期間経過後は速やかに削除します」

→ *すでに3名の方に、この約束をしています。* 決めたら、お知らせが要ります。

■ 決め方の整理

まず、生の録音と、匿名化したあとの記録は *別物* です。
ポリシーにも「録音をもとに、置き換えたうえで記録を残す」と書いてあります。

▼ 案A：用途が終わったら削除（期間を定めない）
　→ ポリシーの「期間を定める」という約束と合いません

▼ 案B：一律で期間を決める（例：1年）
　→ 分かりやすい。ただし生録音を1年持つのはリスクが大きめ

▼ 案C：二段階にする（おすすめ）
　・*生の録音* ：デブリーフと振り返りが終わるまで（例：実施から1〜3ヶ月）
　・*匿名化したあとの記録* ：長めに保持（例：1〜3年）
　→ リスクの高いものを短く、教材として使えるものを長く

■ 決めるときに考えること

・何に使うのか：デブリーフ／研修教材／AI要約
・その用途が終わるのはいつか
・長いほど：教材として使える ↔ リスクが増える

→ *案Cでよければ、数字（生録音◯ヶ月／匿名化後◯年）だけ決めてください。*
　 法務的に確認したいことがあれば、そう言ってください。その場合は会議に回します。
```

## 投稿3｜90日Gateの日程を、どうしますか

```
【90日Gateの日程を、どうしますか】

社長から「リスケしてもいいかも」と出ていた件です。
数えたら、*いまの日程は成立しない可能性が高い* です。

■ 数字

▼ 9/16〜10/5（3週間）に必要なこと
　ロープレ3人 ＋ *実メンバー2人の獲得* ＋ 実施2件 ＋ 観察票の未達0件
　→ 実績は *5週で3件* 。獲得はすべて個別依頼

▼ 10/16〜10/31（2週間）に必要なこと
　*知らない人から1件の入金*
　→ 有償の実績は *0件*

*これまでのペースを超える速度を、サポーター1名のまま前提にしていました。*
しかも9/6の翌日に、発熱で1件飛んでいます。

■ 選択肢（A・B・Cはどれか1つ。Dは他と同時に選べます）

▼ A：期限を延ばす
　「どこまで」を決めないと案になりません。3つの切り方があります。
　・A-1 日付で延ばす（例：12/31）→ *「なぜ12/31か」の根拠がない*
　・A-2 条件で切る（有償化開始から4週間など）→ *無限に延びます*
　・A-3 *上限つき* （12/31を上限、10/31に一度立ち止まる）← いちばん安全
　その先に来る問い：*次も間に合わなかったら、どうするのか*

▼ B：G3（有償）を今期の対象外にする
　10/5にG1・G2を判定して終わり。有償化は次の期へ。
　その先に来る問い：*では、有償E3はいつ取りに行くのか*
　→ 決めないと「あとで」が無期限になります

▼ C：動かさず、Failを受け入れる
　10/31に「G3 Fail」と記録して、そこから設計をやり直す。
　その先に来る問い：*Failだったとき、何をやり直すのか*
　→ 先に決めておかないと、11月がまるごと考える時間になります

▼ D：実行の詰まりを外す（＝投稿0の話）
　→ *これは今回の定例が飛んだことで、必要性が上がりました*

■ Aを選ぶ場合の条件

「間に合わないから延ばす」を無条件に認めると、次も延ばせます。
延ばすなら、*同時にこの3つを書いてください。*
1. 何が足りなくて間に合わなかったのか
2. 延ばした期間で、それがどう埋まるのか
3. *次の期限でも間に合わなかったら、どうするのか* ← これが肝心です

■ 確かめたいことが2つあります（1分で済みます）

① *直近2週間で「会議待ちで止まったこと」が、実際に何件ありましたか。*
　 0件なら「会議を週2にする」は効きません。

② *グロービス界隈への投稿は、もう始まっていますか。*
　 まだなら、それは「会議待ち」ですか、「手が回っていない」ですか。
　（こちらでは分かりません。記録に書かれていないだけです）
　 → ここの答えで、選ぶべき案が変わります。

→ *A-3／B／C のどれか＋Dを入れるか、で返してください。*
```

## 投稿4｜G2（急性期の人）に届く入口を、どうしますか

```
【G2に届く入口を、どうしますか】

無償期間の集客先は、グロービス界隈のFacebookグループ／グループLINE
という前提で整理しました。

■ 先に、議題が軽くなる整理を1つ

*G2 と G3 で、必要な経路の性質が違います。*

・G2（本命条件）：*急性期の人に届くこと* 。反復可能かは問われていない
・G3（有償E3）：*個別依頼の外から来ること* 。急性期かは問われていない

→ *「急性期に届き、かつ反復可能で、かつ有償が発生する経路」を*
*　1つ探す必要はありません。2つ別々でよいのです。*

■ グロービス界隈は、どのゲートに効くか

・G1（供給が2名で立つ）：*届きます。むしろ最適です*
　（条件に「急性期」は入っていないため）
・G2（本命条件）：*届きにくい*
　投稿を見て「話してみようかな」と思える人は、急性期ではありません
・G3（有償・個別依頼の外）：*半分*
　個別依頼の外ではありますが、反復可能な経路とは言いにくいです

→ *グロービス界隈が悪いという話ではありません。* G1にはむしろ最適です。
　 問題は「そこで集めた人を、検証の n としてどう数えるか」だけです。

■ 入口の型は5つ。残り期間で着手できるのは2つだけです

▼ 着手できる
・*型4：すでにいるメンバーからの紹介* → *今日から動きます*
・*型1：当事者コミュニティに出向く* → ただし規約と運営者の確認が先

▼ 間に合わない
・型3：LPの検索登録（SEOは数ヶ月）※広告なら即効性はあるが費用
・型2：クリニック・薬局 → *いちばん筋がよいのに、間に合いません*
・型5：土日・夜に絞る → 入口ではなく差別化。単独ではG2は取れません

※具体的なコミュニティ名は挙げていません。
　実在するか、規約が告知を許しているかを、こちらで確認できないためです。

■ 型1について、1つ注意

*不妊治療の当事者コミュニティは、傷つきやすい人が安心のために集まっている場所です。*
そこに案内を持ち込むことは、*たとえ無償でも、場を壊す形になりえます。*
→ *運営者に先に話を通してください。* それができないなら、この型は使わないほうがよいです。

■ 確かめていない前提が1つあります

*急性期の人は、そもそもオンラインで、見知らぬサービスに申し込むでしょうか。*

投稿を見る → LPを開く → 予約フォームを埋める → *日程の連絡を待つ* → 話す

結果を聞いた当日の人が、この行動を本当にするのか。*一度も確かめていません。*
・するなら → 入口を増やせばG2は取れます
・しないなら → 増やしても取れません。設計そのものを考え直すことになります

→ *「当日・翌日枠を週1つ出す」案が、これを切り分ける仕掛けです。*
　 枠を出して埋まらなければ、「入口がなかった」のではなく
　「*その行動をしない*」側の証拠になります。

■ 選択肢

▼ A：グロービス界隈だけで進め、G2は格下げ（10/5にG2は判定しない）
▼ B-1：＋ メンバーからの紹介（*今日から*）
▼ B-2：＋ 当事者コミュニティ（規約確認が先）
▼ C：G2の条件から「急性期」を外す
　→ 危険：*「本命条件を試した」と言えなくなります。*
　　 進行設計が自分で書いている「初対面×急性期では一度も試していない」が続きます

*AとBは排他ではありません。* B-1とB-2も同時に選べます。

■ その場で確かめてほしいこと

① *3人のメンバーに「もしいたら紹介して」と言える関係ですか。*
　 言えるなら、型4は今日から動きます。
② *クリニックに、誰か接点を持っていますか。*
　 90日Gateには間に合いませんが、「いつから始めるか」だけ決める価値があります。

→ *A／B-1／B-2／C の組み合わせで返してください。*
　 あわせて「当日・翌日枠を週1つ出すか」も、Yes/Noで。
```

## 投稿5｜発話比率65%を、ゲートにしますか

```
【発話比率65%を、ゲートにしますか】

品質の担保をどこに置くか、9/7で論点に出て決まらずに終わった件です。

■ 提案している3つの層

▼ ①赤い線（絶対）
　禁止フレーズ5つ／医療的助言・病院の評価／Yellow・Redの見落とし／私的な記録・共有
　基準：*すべて0件*
　未達なら：*有償化しない。* 該当者はサポーターから外す

▼ ②有償化の条件
　観察票の未達／メンバー発話比率／サポーター負荷
　基準：未達0件／*65%以上* ／7未満
　未達なら：有償化を延ばす

▼ ③育てる目標
　メンバー発話比率：*70%以上*
　未達なら：*止めない。* デブリーフで扱う

※①の赤い線は、*3件とも守られています。* 未達が続いているのは②だけです。

■ 争点は「65%」という数字です

実績は9/6で51%（本編のみ58%）。目安は70%です。
いきなり70%をゲートにすると、*おそらく誰も通りません。*

*ただし、65%に根拠はありません。*
「現状+7〜14ポイント」という以外の理由がなく、*サンプル1件から引いた線* です。

■ 選択肢

▼ A：65%をゲートにする
▼ B：*発話比率はゲートから外し、育てる目標だけにする*
　　 有償化の条件は「観察票の未達0件」と「負荷7未満」の2つだけ

→ Bの考え方：発話比率は *サポーターの訓練の指標* であって、
　 *メンバーが価値を感じたかどうかとは別* です。
　 有償化の可否に使うのは、筋が違うかもしれません。

→ *AかBか、だけ返してください。*
```

## 投稿6｜G1とG2、どちらを先にしますか（投稿3・4のあとで）

```
【G1とG2、どちらを先にしますか】
※投稿3（日程）と投稿4（経路）が決まってから投げます

■ 3つのゲート

▼ G1：供給が2名で立つ
　① 代表1以外の2名がロープレ完了
　② その2名が実メンバーと各1件
　③ *その2件で観察票の必須項目未達が0件*

▼ G2：本命条件で1件
　初対面 × 急性期（今まさにつらい）× 知人枠でない経路

▼ G3：有償が1件
　実際に入金が発生した1件。かつ経路が個別依頼の外

■ 争点は、条件そのものより *順番* です

▼ A：G1とG2を並行
　両方判定できる。*ただし代表1の負担が上がります*

▼ B：G1を先に通し、G2は後に回す
　負担は下がる。*ただしG3の判定は、ほぼ不可能になります*
　→ Bを選ぶなら「*G3は判定しない*」も同時に決めてください
　　 あとで「通らなかった」ではなく「*そもそも取りに行かなかった*」と記録するためです

■ 投稿4との関係

*グロービス界隈からG2の条件を満たす人が来る可能性は低いです。*
そうであれば、*A（並行）を選んでもG2は取れないかもしれません。*
→ 投稿4の答えとセットで考えてください。

→ *AかBか、だけ返してください。*
```

```
　→ *どちらでもよいと思います。*
　　「書いてあるが使われていない」状態を続けるのがいちばん悪い、とだけ。
　→ G1/G2/G3が決まれば実務上は回るので、10月でも間に合います
```

## 投げる順番と、その理由

| 順 | 投稿 | なぜこの順か |
|---|---|---|
| 1 | **投稿0（進め方）** | **これが通れば、残りが全部Slackで回ります。** 最初に置く |
| 2 | 投稿1（アンケート） | **足さないまま実施すると取り返せない。** 実施が入る前に |
| 3 | 投稿2（保存期間） | **期限9/20。** 8日後 |
| 4 | 投稿3（日程） | 10/5の判定に直結 |
| 5 | 投稿4（経路） | 投稿3と並行でよい |
