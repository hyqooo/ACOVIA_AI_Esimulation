# 2029年イベント骨子（テーマ：専業化第1号。メディア掲載と、逆方向レポートが保険として機能した年）

前年末状態：現金404.5万円／会員100名／サポーター10名／役員報酬 各10万円/月／法人4件（B2B月40万→1月から60万）／株式会社ACOVIA／持ち越し＝代表2専業化条件（2029年5月会議・月次営業利益3ヵ月平均60万円以上なら7月から67万円）

## 正式経営会議（4回）
- **第10回 2/3**：法人6件化（クリニックA/B/C'・企業A/B/C。B2B月60万円）。会員システム刷新（3月・80万円）の承認。5月納付の法人税77.4万円の資金確認
- **第11回 5/5**：**代表2専業化の判定**——事前定義（3ヵ月平均営業利益60万円）に対し実績約73万円（2〜4月平均・仮定）→**条件成立、7月から報酬67万円**。CHRO対CFO：残る2名との報酬差（67万対15万）の心理的影響→「差は条件の差であり評価の差ではない」を文書化。代表1・3は15万円へ
- **第12回 8/4**：メディア対応方針の事前決定（10月にN新聞の取材が内定→**掲載前に**供給計画・待機運用・「何者かを外の言葉で説明する一文」を確定。失敗パターン13対策）。5期生研修の前倒し承認
- **第13回 11/3**：メディア掲載の総括（申込急増→待機→セルフキット振り分けが機能した数字）。**逆方向レポートへの批判（SNS）の総括**：「治療をやめさせる会社」という投稿が拡散しかけたが、2027年から四半期公開してきたレポートと利用者の反論で3日で沈静化（Hとの差＝平時からの公開。学び5が保険として機能した実例）。2030年予算：**代表1・3の報酬67万円化（1月）と専業化（4月）を決定。2030年が営業利益率1%台の谷になることを予算書に明記した上で決定**（谷を予定にする）
