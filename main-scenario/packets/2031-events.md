# 2031年イベント骨子（テーマ：到達の年。1,000万円・5年レビュー・次の5年の撤退条件）

前年末状態：現金905.7万円／会員290名／サポーター18名／報酬 各67万円/月→1月から各84万円（年1,008万円）／法人13件（B2B月140万→1月から160万）

## 正式経営会議（4回）
- **第18回 2/1**：報酬84万円化の初月確認（1月単月▲2.7万円＝想定内、と予算書参照）。7期生研修承認。**質問体系の追加公開（G部品の拡張）を議論開始**：ソーシャルインパクト「セルフ整理キットの完全版をCC BYで公開し『規格』を目指す」対 VC「法人契約の中身を無償公開すれば堀が消える」対 CEO→結論は5月へ持ち越し（保留1回目）
- **第19回 5/3**：**質問体系の公開範囲を決定（保留2回目で決定＝ルール内）**：セルフ整理キット完全版はCC BYで公開・サポーター研修教材と評価基準は非公開を維持。「個人が自分で使うものは公開、法人・供給の再現に関わるものは非公開」という線を文書化。法人税15.2万円納付
- **第20回 8/2**：会員370名到達見込みの供給計画（22名体制・稼働上限12件は5年間不変であることを確認）。介護領域の再検討（2030年持ち越し）→**「有償の研修提供のみ・2032年から小規模に」と決定、事業展開はしない**
- **第21回 11/1（5年レビュー）**：①儲け指標4つの確定（800万=2030／1,000万=2031／利益率6.8%／累積1,267万円）②12の学びの検証結果（各1行）③失敗パターン13種で「起きたもの・起きかけたもの・起きなかったもの」の棚卸し ④**次の5年（2032〜2036）の撤退条件・反証条件の更新**（例：会員純減が3四半期連続→B2C縮小、法人更新率70%未満→B2B価格改定、など数字で）⑤成功の定義（憲法）に照らした自己判定——年商1億円ではないが、MVV達成・長期継続・3名専業を根拠に「成功」とする案を各部署が判定（**割れてよい**。vc-reviewには慎重な判定を出させる）
