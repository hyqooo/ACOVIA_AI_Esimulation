# 2030年イベント骨子（テーマ：専業化の谷。予定どおり沈み、予定どおり浮上する年）

前年末状態：現金1,081.5万円／会員200名／サポーター15名／報酬：代表2 67万・代表1/3 15万→1月から全員67万円／法人9件（B2B月90万→1月から115万）／2030年が営業利益率1%台の谷になることは2029年11月の予算書に明記済み

## 正式経営会議（4回）
- **第14回 2/2**：1月の月次赤字（▲29.0万円）の確認。**「これは2029年11月に予算書へ書いた谷である」ことを固定議題④で読み上げてから議論する**（先に決めてあったので動じない、が今年の主題）。VC「予定どおりの赤字でも赤字は赤字。谷の出口条件（6月黒字化）を再確認する」
- **第15回 5/4**：3月の大幅赤字（▲80.4万円＝システム改修60万円を含む）と5月の法人税226.3万円納付を通過した後の現金確認（5月末699.6万円。最低ライン70万円・凍結ライン50万円から十分な距離）。**介護領域の企業（仮名：企業H）から「介護離職の意思決定支援をやってほしい」という引き合い→断る**。CEO「ドメインは不妊治療に閉じる。Fの部品は取らないと2026年に決めた」対 CFO「年240万円の契約見込みを断る記録は残す」→断った上で、知見譲渡（有償の研修提供のみ・2031年に再検討）を持ち越しに
- **第16回 8/3**：**Value差分チェックが初めて実際の差分を検出**：7月改訂の法人向けパンフに「最適な選択をサポートします」の一文→Agency（選ぶ力を返す）の主語が自社に移りかけ（Kの前兆と同型）→原文「選ぶのはあなたです。私たちは選ぶ力が戻る場を作ります」へ差し替え。**検出から差し替えまで11日。Kはこれを5年間検出できなかった**
- **第17回 11/2**：4〜6月に代表1・3が専業化して以降の運営総括。2031年予算（報酬各84万円=年1,008万円）。5年レビュー（2031年11月）の設計開始
