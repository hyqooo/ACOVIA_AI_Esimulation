| ①利用瞬間 | 有償申込の**50%以上**が特定場面（期待より悪い結果の当日〜翌日）に集中し、同型場面が反復する |

| ④再現性・経済性 | サポーター間の7日後指標の差が説明可能で、1件あたり原価が実測で説明できる |
| ⑤流通・支払者 | **非知人に届いた経路が実在**し（R2-1の31件）、支払者候補（本人以外を含む）が1つ以上言語化される |

| ①利用瞬間 | 52件中30件（58%）が「悪い結果の当日〜翌日」 | **Pass** |

| ④再現性・経済性 | サポーター4名間の差は小（n不足）。原価は実測で説明可能（1件あたり変動△126円＝お試し期の意図した赤字） | **条件つき**（n=52では再現性を語れない） |
| ⑤流通・支払者 | 非知人経路は実在（個別案内・紹介）。**ただし「本人以外の支払者候補」はゼロ**（法人を入れない設計のため構造的） | **Fail寄りの条件つき。課題として登録** |
