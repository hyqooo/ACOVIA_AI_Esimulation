## この物語の3つの山

1. **2027年7月、初めて企業からお金が振り込まれた。その商品は相談窓口ではなく研修だった。** D-019（予防・啓蒙の解禁）がなければ、2027年の売上はゼロに近かった。同時に、この発見はB社の一言（2026年10月）から**9ヶ月遅れた**
2. **2028年2月、KIBOW賞を受賞。大賞は逃した。** 講評は「財務的リターンの主柱と、現に売れている商品が一致していない」——`growth-v3`が自分で「最も弱い」と書いた場所を、そのまま突かれた
3. **2028年12月、利用率がKill条件に触れる。** 6社中4社が3%未満。同時に「**利用率が上がると赤字になる**」という定額契約の構造的欠陥を発見し、売れる先を自分から狭める決定を下す。これがこの5年で最も価値のある判断だった

## 最大のボトルネックは、資金でも需要でもなく稼働だった

2026〜2028年、この会社が動ける時間は**週25〜32時間**（フルタイム1人未満）。10億円に1.8億円届かなかった差は、ほぼこの制約に由来する。

- ARPUの見積もりが35%高すぎた（計画240万円 → 実績196万円）
- 最初の営業担当が座ったのが**創業から2年後**（2028年10月）

## 現実に、いま持ち帰れる5つ

1. **研修メニューをいま作る**（90分・45〜60万円）。保険ではなく、最初に売れる商品
2. **人事部への質問を差し替える**——「買いますか」ではなく「自社に何人いると思いますか、観測できていますか」
3. **接触の時期を年度に合わせる**——4〜6月は期ずれ。**9〜11月に集中**
4. **セッションの実所要時間を測る**——30分のセッションに準備・記録・振り返りで70分
5. **300名未満に単独契約を売る設計を作らない**——匿名性が確保できず使われない
