# 04｜2029〜2031年：拡大と、10億に届かない理由

> ここから先は四半期単位で書く。**この3年間で事業は本物になる。そして、5年で10億円には届かない。**

---

## 2029年｜シリーズAと、ARPUの発見

### Q1（1〜3月）

- 価格改定を4月更新分から適用すると決め、既存6社に説明。**5社が受け入れ、1社（G社・窓口のみ契約）が解約。** 初の解約だが、そもそも利用率1.1%で更新しても意味がなかった契約である
- 新価格：**基本料（年150〜250万円、研修年4回＋相談枠年40件まで）＋超過分 1件18,000円**
- **菅原さんが専業化**（4月付。役員報酬1,200万円）。兼業期間は2年8ヶ月だった
- 山口さんが3月に大学院を修了。**週20時間の業務委託に増える**（フルコミットはまだ）

### Q2（4〜6月）

- 4月に年度が変わり、**新規9社が同時に立ち上がる**（前年秋に仕込んだ稟議が年度開始で通った）。B2Bの季節性がはっきり見える：**契約の6割が4月開始**
- カスタマーサクセス1名、サポーター統括1名を採用（正社員4名体制）
- **大企業との最初の商談**。J社（従業員1万2,000名の金融）。健保組合が窓口となり、グループ7社への一括導入を検討。**提示額は年間800万円**
- J社の稟議は9ヶ月かかる。**大企業は単価が高いが、時間も比例して長い**

### Q3（7〜9月）

- **シリーズA、3.2億円で調達完了**（Pre 13億円）。リード投資家は社会的インパクトを重視するファンド。KIBOW賞と、2年分の利用率データが効いた
- 投資契約に**D-017の業績連動条件3つ（売上計画比100%以上／粗利率55%以上／支給後ランウェイ12ヶ月以上）を明記**。役員報酬テーブルも別紙で確定。**後出しにしなかったことで、報酬の議論は30分で終わった**
- 自治体：**D-020のとおり、政令市の若年層向けライフプラン講座を随意契約で受託（150万円）。実績1件目**。予防・啓蒙の解禁がなければ、この入り口はなかった
- 男性利用率が**5.8%**に上昇。効いたのは2つ——男性サポーター2名の顔と経歴を社内告知に載せたこと、「パートナーが治療中の方も対象です」と明記したこと

### Q4（10〜12月）

- 営業3名体制。**年末で有償法人42社**（年間契約28社、研修単発14社）
- **売上 約6,800万円**（年間契約 4,300万／研修 1,400万／超過課金 480万／自治体 150万／C向け・研修認定 470万）
- 第2ドメイン（介護）の初期調査を開始。**既存顧客の人事部に聞くと、7社中6社が「介護のほうが対象者は多い」と答えた**
- **中間ゲート（2029年に70社）に対し42社。未達。**

> 【CFO】ここで10億円の等高線を引き直す必要がある。当初は「250社×240万円」だった。**しかし実際のARPUは、年間契約28社の平均で154万円。** 想定より35%低い。理由は、300名未満を売らないと決めたことで中堅が中心になり、かつ研修セット化で価格を上げにくかったこと。
>
> 一方でJ社のような大企業は800万円。**社数ではなくARPUミックスを変えないと、10億円には届かない。**

## 2030年｜報酬2,000万円に、わずかに届かない

### Q1〜Q2

- **J社の導入が決定**（4月開始、グループ7社一括、年間840万円）。初の大企業。以後、大企業向けの提案が営業の主戦場になる
- 営業6名体制。年間契約の平均単価が**168万円**に改善（大企業の混入効果）
- 自治体2件目・3件目を受託（合計520万円）。**実績要件をクリアし、2030年度から相談事業のプロポーザルに単独応募できる状態になる**
- 男性利用率**8.4%**。全国の相談窓口における男性比率（約16%）にはまだ届かない

### Q3〜Q4

- **有償法人98社**（年間契約71社、研修単発27社）。うち大企業（5,000名以上）4社
- 介護ドメインのパイロットを既存顧客5社で開始。**有償転換は2社**（1社あたり年80万円）
- Decision Guide β（サポーター支援AI）が全セッションで稼働。**1セッションあたりの記録・要約時間が70分→28分に短縮**。粗利率が57%→62%へ改善
- **売上 約2億4,000万円**

**そして12月、報酬の判定が来る。**

| 項目 | 数値 |
|---|---|
| 売上 | 2億4,000万円 |
| **年初計画** | **2億5,300万円** |
| 計画比 | **94.9%** |
| 粗利率 | 62%（条件クリア） |
| ランウェイ | 19ヶ月（条件クリア） |

**業績連動の支給条件①「売上が計画比100%以上」を満たさない。** 連動部分は支給されず、菅原さん・倉元さんの報酬は**基本1,500万円のまま**。

> 【CFO】D-017で決めた条件が、そのとおりに機能した。**2,000万円には届かなかったが、これは失敗ではなく設計どおりである。** 計画未達の年に賞与が出ないことこそが、投資家に対して報酬テーブルを正当化していた根拠だった。
>
> 【VC】むしろ言うべきはこうだ。**もし条件を「計画比90%」にしていたら、今年2,000万円を払えていた。** 条件をどこに置くかが、そのまま到達年を決める。100%は厳しめの設定だった——それは経営陣が自分で選んだ厳しさである。

- 12月、**シリーズB 6億円を調達**（Pre 42億円）。第2ドメインと大企業展開が評価された

## 2031年｜8億2,000万円。10億には届かない

### 通年の動き

- 営業14名。**有償法人196社**（年間契約152社、研修単発44社）。うち大企業11社
- ARPUミックス：大企業11社×平均760万＝8,360万／中堅141社×平均185万＝2億6,100万
- 自治体：相談事業のプロポーザルに3件応募し**2件受託**（合計1,100万円）。実績要件を越えた効果が出る
- 介護ドメイン：18社（年間平均95万円）＝1,710万円
- サポーター：稼働132名（うち男性26名）。認定研修の受講料収入 2,400万円
- 男性利用率**11.2%**

**売上 約8億2,000万円。**

| 収益線 | 2031年売上 |
|---|---|
| 年間契約（企業） | 3億4,460万円 |
| 研修単発 | 1億3,200万円 |
| 超過課金 | 8,900万円 |
| 大企業向け拡張メニュー | 6,200万円 |
| 自治体 | 1,100万円 |
| 第2ドメイン（介護） | 1,710万円 |
| サポーター認定研修 | 2,400万円 |
| C向け・その他 | 4,030万円 |
| **合計** | **約8億2,000万円** |

- 粗利率 64%。**EBITDA ＋3,100万円で初の通期黒字**
- **報酬：計画比103%を達成し、業績連動が満額支給。菅原さん・倉元さんとも総額2,000万円に到達**（基本1,500万＋連動500万）

### 10億円に届かなかった差の内訳

不足は1億8,000万円。**その差がどこで生まれたかは、はっきりしている。**

| 要因 | 影響額（推定） | 中身 |
|---|---|---|
| **ARPUが想定より低い** | ▲1億1,000万 | 計画240万円に対し実績196万円（全契約平均）。300名未満を売らないと決めた副作用でもある |
| **営業採用が1年遅れた** | ▲6,000万 | 最初の営業採用が2028年10月。2027年に業務委託でも入れていれば、2029年の立ち上がりが1年早かった |
| **研修セット化による契約単価の抑制** | ▲4,000万 | 利用を作るために研修を増やしたが、その分を価格に転嫁しきれなかった |
| 大企業の獲得（プラス要因） | ＋2,300万 | J社以降の11社。これがなければ7億円台前半だった |
| 自治体・第2ドメイン（プラス要因） | ＋900万 | 想定より小さいが、2032年以降の柱になる |

**2032年の見込みは11〜12億円。** 10億円の達成は**2032年**であり、5年（2031年）ではなく**6年**かかった。
