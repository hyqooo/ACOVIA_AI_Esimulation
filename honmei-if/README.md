## なぜ本体と分けているか

本命シナリオ（`../honmei/`）は、5.5年・62ヶ月・23回の経営会議を積み上げた**運営文書**である。

本書はその**批評**である。批評が本体と同じ場所にあると、**どちらが「決めたこと」なのかが混ざる**（`secretary/` の第一の役割：決まったことと、まだ決まっていないことを、混ぜない）。

したがって別枠に置く。**本体を読む人は、こちらを読まなくてよい。**

## 6つの問いと、その判定

| 問い | 判定 |
|---|---|
| 1. 既存の役割（利用者・提供者・専門家）を前提にしていないか | **痛い** |
| 2. 二項対立（相談する人／相談される人）を固定していないか | **痛い。ただし一部は正当な理由がある** |
| 3. 価値の流れは一方向ではなく循環できないか | **いちばん痛い（実務上）** |
| 4. 競争している市場そのものを再定義できないか | **痛い** |
| 5. ネットワーク効果や学習効果はどこで生まれるか | **最も痛い** |
| 6. 10年後、AIが普及した世界でも強いままか | **半分痛い** |

### 問い5がいちばん厳しかった理由

**この事業は、人が増えるほど体験が悪くなる構造を持っている。**

- 相談者が増える → 枠が埋まり、申込→実施が遅くなる
- サポーターが増える → 品質の分散が広がる（実測：2名で5.5pt → 174名で26.1pt）
- 法人契約が増える → 従業員支援枠が本人向けの枠を圧迫する

5.5年で品質指標の定義を変えた（決定17-7）のは、**基準が守れなくなったからである。**

**唯一、規模が効く資産は「逆方向の数字」だけだった。** 2027年から取り続けた推移は、2036年には買えない。

## 採決の結果（21案）

**採択9案／条件つき採択6案／不採択6案。保留ゼロ。**

**第3群（枠そのものを変える4案）は、4案とも不採択。** つまり**この会社は、枠を変えないと決めた。**

ただし、**不採択の理由が4案とも違う。ここを混ぜてはいけない。**

| 案 | 不採択の理由 |
|---|---|
| **B-1**（相互セッション） | 構造として間違っているのではなく、**安全設計が追いつかない**。追いつかせる方法は思いついていない |
| **A-1**（段階で切る） | **判断材料がない。** サポーターの「治療を終えた時期」を5.5年記録していなかった |
| **B-2**（3人目を入れる） | **顧客にとって何が良くなるかを、会議で説明できなかった** |
| **F-4**（AIを前半15分に） | 3つの条件を数字で書いた。**条件が揃えば採る** |

## この一連の作業で初めて明らかになった、5.5年間の空白（3つ）

1. **法人研修について「受講後に言えるようになったか」を一度も測っていない。** 本人向けでは7日後に測っているのに、**法人相手のときだけ失敗パターン1（「いいサービスですね」で終わる）を放置していた**
2. **サポーターの「治療を終えた時期」を記録していない。** 「経験者であること」だけを要件にし、経験の新しさを一度も見ていない
3. **前半15分が「人間でなければならない」ことは、一度も証明されていない。** 2027年の検証（決定2-4）が示したのは「前半15分は**必要だ**」までであり、「**人間でなければならない**」ではない

## いちばん価値があると考えるもの

**E-1 × E-2（場面カテゴリ × 6ヶ月後の結果）。**

- **5.5年で1円も生まない**
- しかし **10年後にAIが原理的に持てない唯一の資産**になる（AIは会話を大量に持てるが、「その後どうなったか」は本人が教えてくれない限り持てない）
- そして **今日から始められる。** 27,644件の自由記述は、本命シナリオの中ですでに集まっている。**分類しなおすだけである**

## `vc-review/` の最後の指摘

> 今日の結論は「枠を変えない」でした。それでいいと思います。
>
> ただし、**第3群を4案とも落とした理由のうち、3つは「材料がない」「説明できない」「追いつかない」でした。**
>
> **それは「変えなくてよい」ではなく「変えられなかった」です。混同しないでください。**
>
> **何が観測されればこの指摘は消えるか**：今日書いた3つの測定——法人研修の7日後フォロー、サポーターの治療終了時期、前半15分の比較群——が、**1年以内に3つとも動き出すこと。**

## 2026年8月4日｜現実側の資料が入ったあとの状態

社長から現実のACOVIAのNotion 2ページが渡され、6つの問いを再点検した（→ [`04-reality-reopen.md`](04-reality-reopen.md)）。

**枠を変えないという結論は、変わっていない。変わったのは、変えない理由の質である。**

| 変わったこと | 中身 |
|---|---|
| **問い3の答えは、すでに本体の中にあった** | 現実のACOVIAの最新フェーズは **Phase7｜前提変革・循環構造レビュー「支えられた人が次を支える仕組み」**＝問い3そのもの。本命の**恩送り（2028年1月〜のサポーター認定プログラム）がまさにそれ**だが、構造レビューは「供給の確保手段」として書いたため、循環として数えていなかった |
| **A-1の「材料がない」が崩れた** | 材料が取れないのではなく、**取る発想が22回の会議で一度も出なかった**。現実側は「経験者であることの必要性」を**要件ではなく検証対象**として扱っている |
| **F-4に数字の条件が1本増えた** | 「**1人当たり処理量2倍以上・品質非劣性**」（サブの案 B-50）。これを満たさないなら、AIを前半15分に置いても原価は半分にならない |
| **7つ目の問いが追加された** | **「この構造は、誰を排除しているか。排除された人は、こちらの記録に現れるか」**。6つの問いは、**払える人／払えない人という、いちばん固い二項対立を問わなかった** |
